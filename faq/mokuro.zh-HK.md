如果你在日語學習社群裡找過「漫畫怎麼查詞」，大機率聽說過 mokuro。這篇講清楚它是什麼、`.mokuro` 檔案裡裝的是什麼，以及 Fushi 裡和 mokuro 相關的三件事：匯入現成的 `.mokuro`、呼叫你自己裝的 mokuro 命令列、瀏覽內建的 Mokuro 目錄。

## mokuro 是什麼？

[mokuro](https://github.com/kha-white/mokuro) 是一個開源的命令列工具：你給它一個裝著漫畫頁圖的資料夾，它在電腦上逐頁檢測對話方塊、識別裡面的日文，然後輸出識別結果。用瀏覽器開啟它配套的閱讀器，就能在漫畫圖片上選中文字，再用 Yomitan 之類的瀏覽器查詞工具查詞。

它的意義在於把「漫畫是圖片、字選不了」這個門檻拆掉了。代價是要在電腦上裝 Python 環境和模型、整卷跑一遍識別，而且識別結果和查詞、制卡是幾樣分開的工具。

新版 mokuro（v0.2 起）把一卷的識別結果寫成一個 `.mokuro` 檔案，本質是一份 JSON：記錄每一頁的尺寸、每個文字框的位置、是不是豎排、框裡每一行的文字。頁圖本身不在裡面，通常放在與 `.mokuro` 同名的資料夾裡，兩樣合起來才是完整的一卷。

## Fushi 怎麼讀 .mokuro？

Fushi 的漫畫閱讀器內部就用 mokuro 的資料格式：不管文字是 mokuro 識別的、還是 Fushi 自己的漫畫 OCR 識別的，結果都落進同一種結構，閱讀器據此在圖上疊一層看不見的文字，**點字即查詞**，點加號制卡（卡上帶對話方塊那一整句和這一頁的畫面，詳見[本地漫畫怎麼匯入](/faq/manga-local.zh-HK)）。

匯入現成的 mokuro 卷：底欄 **漫畫** → **匯入** → **匯入漫畫**，然後任選一種方式：

- **選那個 `.mokuro` 檔案**：Fushi 按 `.mokuro` 裡記錄的路徑去找旁邊的頁圖；
- **選裝著 `.mokuro` 和頁圖資料夾的那個資料夾**：資料夾里正好一個 `.mokuro` 時，按這一卷匯入，OCR 結果一起帶上——不會被誤當成普通圖片資料夾而把文字丟掉；
- **選一個裝著多卷的資料夾**：直接子層有多個 `.mokuro` 時，按批次匯入逐卷各導一本，每卷帶各自的 OCR；
- **CBZ / ZIP 加同名 `.mokuro`**：`book.cbz` 旁邊放著 `book.mokuro` 的佈局也認。

**iOS 上要注意**：iOS 單選一個 `.mokuro` 檔案時帶不上它旁邊的頁圖（系統只給你那一個檔案的訪問權）。請選整卷資料夾（含 .mokuro 和它的頁圖資料夾），或者把整卷打包成 .zip / .cbz 再匯入。

頁圖對不上時 Fushi 不會靜默匯出一本沒字或缺頁的漫畫，而是報出具體哪一頁找不到圖，方便你檢查資料夾結構。匯入後如果你又對這卷跑了一次識別，OCR 嚮導會提醒「本卷每一頁都已有 OCR 資料，無需再跑（重跑會覆蓋現有資料）」。

## 不用 mokuro 也能識別：Fushi 自帶漫畫 OCR

很多人以為在 Fushi 裡讀漫畫必須先用 mokuro 處理，其實不用。Fushi 自帶 **漫畫 OCR**：在 **設定 → 漫畫 → 漫畫 OCR** 下載本機模型後，匯入任何 CBZ / ZIP / PDF / 圖片資料夾都能在閱讀器裡直接識別，結果同樣存成 mokuro 格式，下次開啟不用重跑。識別在本機進行，五個平臺都能跑預設的本機模型；手機算力不夠的話還能把識別交給已配對的 Fushi 互聯服務端（見[Fushi 互聯](/faq/interconnect.zh-HK)）。各引擎的差別和調優見[漫畫 OCR 認不準怎麼辦？](/faq/manga-ocr-tips.zh-HK)。

所以 mokuro 在 Fushi 裡更像一個「可選的外部引擎」和「現成資料的來源」：你以前用 mokuro 處理過的漫畫庫，可以原樣搬進來繼續用。

兩條路怎麼選，可以按這幾點判斷：

- **只在手機或平板上讀**：用 Fushi 自帶的識別就夠了，不需要電腦，也不用先整卷跑完——「開啟即識別」會從你當前看的那頁開始識別，邊讀邊出字；
- **已經有一整個用 mokuro 處理過的庫**：直接匯入 `.mokuro`，幾百卷也不必重新識別；
- **對某個識別器的效果有偏好**：桌面端可以在自帶模型和外部 mokuro 之間切換著試，同一卷識別過的結果會覆蓋成新引擎的結果；
- **不想反覆識別**：不管用哪個引擎，識別結果都存進這本漫畫自己的資料（mokuro 格式），之後開啟就是帶字的，只有你主動「重新識別本卷…」才會再跑。

## 在 Fushi 裡呼叫你裝的 mokuro（僅桌面）

已經在電腦上裝好 mokuro、習慣它的識別效果的話，可以讓 Fushi 直接呼叫它：

1. **設定 → 漫畫 → 漫畫 OCR** 的「外部工具」分組裡，填 **外部 mokuro 命令列路徑**；留空則自動探測（先看環境變數 `FUSHI_MOKURO`，再找 PATH 上的 `mokuro`）；
2. 點 **檢測**，顯示「已檢測到：版本號」就說明找到了；
3. 把 **預設 OCR 引擎** 改成 **外部 mokuro**（「呼叫你自己安裝的 mokuro 命令列，僅桌面可用」）。

之後用 OCR 匯入嚮導或閱讀器的「識別本卷」時，Fushi 會對圖片資料夾跑 mokuro，拿到 `.mokuro` 產物再匯入。常見報錯都有明確提示：「未找到 mokuro 執行檔」「mokuro 長時間無輸出，已超時終止」「mokuro 以非零退出碼結束」「mokuro 執行完成但未找到 .mokuro 產物」，按提示檢查路徑和 mokuro 本身能不能在命令列裡跑通即可。

## 內建 Mokuro 目錄：直接下載帶 OCR 的卷

漫畫來源裡有一個 **內建 Mokuro 目錄**（預設站點是 mokuro.moe 的目錄），裡面是社群整理好、已經附帶 `.mokuro` OCR 資料的漫畫：

1. **瀏覽 → 來源**（漫畫庫的「來源」子標籤也一樣）選「漫畫」，開啟 **內建 Mokuro 目錄**；
2. 用「搜尋系列」找到作品，勾選想要的卷，點 **下載所選**；
3. 每卷分三步：「下載 OCR 資料…」→「下載捲包…」→「解包中…」，大的捲包支援斷點續傳，服務端臨時故障會自動重試；進度在下載佇列的「漫畫目錄下載」裡看，完成後顯示「已入庫」。

下完直接讀、直接點字，不需要再識別。這一行和擴充套件提供的漫畫源在同一個列表裡，左側開關關掉後它就不出現在「瀏覽」裡；目錄站點地址可以在 **設定 → 漫畫** 的「線上目錄」分組裡改（「線上目錄地址」，留空即預設站點）。

**平臺限制**：內建 Mokuro 目錄屬於線上漫畫源，**iOS 版按 App Store 規定沒有這個功能**（和 Mihon 擴充套件源一樣），Android、Windows、macOS、Linux 可用。iOS 使用者仍然可以在電腦上準備好 `.mokuro` + 頁圖，打包成 CBZ / ZIP 後匯入 iPhone / iPad 閱讀，見[iOS 版少了哪些功能？](/faq/ios-limits.zh-HK)。

還想找更多線上漫畫來源，看[Mihon / Aniyomi 擴充套件是什麼？](/faq/mihon.zh-HK)和[線上看漫畫](/faq/manga-online.zh-HK)。
