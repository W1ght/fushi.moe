Fushi 里所有「查词」最后都落到同一个东西上：**查词弹窗**。阅读器、视频字幕、漫画 OCR、Galgame 浮窗、首页的查词页、电脑上的全局查词、浏览器扩展，弹出来的都是同一套弹窗——同样的词典顺序、同样的排版、同样的加号制卡。学会一处，处处都会。

还没装词典的话先看[怎么导入词典](/faq/dictionaries)或者直接装[推荐包](/faq/pack)；弹窗里一片空白，九成是词典还没装好。

## 怎么触发查词：点击、悬停、Shift

| 在哪 | 怎么查 |
|---|---|
| 阅读器正文、视频 / 番剧字幕、漫画 OCR 文字、Galgame 台词浮窗 | **点一下**那个词 |
| 桌面端（Windows / macOS / Linux），打开「悬停即查词」后 | 鼠标**停在**字上就查，不用点 |
| 浏览器扩展（任意网页） | **按住 Shift** 移到词上，见[浏览器里怎么查词](/faq/browser-lookup) |
| 首页的查词页 | 输入或粘贴一段文字，再点其中的词 |

点的是**一个位置**，不是一个词：Fushi 从你点的那个字开始往后取一段文字，交给词典引擎做「最长匹配」——能匹配上的最长词条排在最前面。所以点「食べられなかった」的「食」，结果会是「食べる」；点到「べ」上就只会从「べ」开始匹配。点词头的第一个字，结果最准。

几个和触发有关的设置，都在 **设置 → 查词 → 查词触发**：

- **悬停即查词**：鼠标悬停在文字上即自动查词，无需点击或按住 Shift；最多触发一层弹窗。仅桌面端。默认关。
- **离开查词即继续播放**：视频里悬停查词后，鼠标离开字幕和弹窗就自动关掉弹窗并继续播放。默认开，只对悬停发起的查词生效。
- **扫描非日文文本**：关掉后，选区遇到非日文字符就停，不会把旁边的英文字母、数字一起吃进去。默认开。读日语以外的语言时保持开着。
- **结果中的词头数量上限**：一次最多列多少个词头。调小弹窗更短，调大能看到更多「也可能是这个词」的候选。

另外 **设置 → 查词 → 朗读与反馈** 里的「查词时暂停」（默认开）会在查词时暂停视频 / 有声书，关掉弹窗后继续。

## 弹窗里有什么：多词典、变形说明、音调、词频

一个词条从上到下大致是：

1. **词头和读音**，旁边是**喇叭**（播放单词发音）和**加号**（制卡）。
2. **变形说明标签**：你点的是「食べられなかった」，词条是「食べる」，中间会挂几个小标签说明它经过了哪些变形（可能态、否定、过去……）。有说明的标签悬停可以预览、点击可以钉住一段语法解释。
3. **音调**：装了音调词典才有，读音上画高低线，后面跟着 `[0]`、`[2]` 这种数字，详见[怎么显示日语音调](/faq/pitch-accent)。
4. **词频**：装了词频词典才有，显示这个词在各本词频表里的排名，详见[词频词典是什么](/faq/frequency)。
5. **各本释义词典**的释义，按你在词典管理里排好的顺序一本一本往下列。

词典多了弹窗会很长，**设置 → 查词 → 词条内容** 里有几个开关专门治这个：

- **折叠词典显示**（默认开）：每本词典默认收起，点标题展开。配合「自动展开行数」，可以让前一两行词典始终展开，后面的收起。
- **词典最多列数（自动填充）**：宽屏上把词典方框排成多列，窄屏会自动减少列数。
- **紧凑释义**：释义条目同行显示、用「 | 」分隔，不再每条占一行。
- **显示表达标签**：显示词头上的词性 / 用法标签。

词典的顺序、隐藏、单本折叠在 **设置 → 查词 → 词典管理** 里调；字体、颜色在「词典样式」里改，每本词典可以单独设。

### 词形还原：为什么点变形后的词也能查到原形

日语的动词、形容词变化很多，词典里只收原形。Fushi 的词典引擎带一套**词形还原规则**：把你点到的那段文字按规则逐步倒推（なかった → ない → 否定前的形态 → 原形），再拿每一个候选去词典里找，找到的就排进结果，并把推导过程显示成上面说的变形标签。

不止日语。Fushi 内置了日语、英语、德语、法语、西班牙语、韩语、阿拉伯语、拉丁语等十几种语言的还原规则；英语还单独处理不规则变化和短语动词（gave up → give up）。没有还原规则的语言照样能查，只是要点到原形才命中。可查的语言由你导入的词典决定，见[只能学日语吗](/faq/languages)。

## 弹窗里再点词：递归查词（嵌套弹窗）

释义里又冒出不认识的词？**直接在弹窗里点它**。Fushi 会在当前弹窗之上再叠一层新弹窗，查这个新词；新弹窗里还能接着点，一层一层往下钻。这就是 Yomitan 用户说的「递归查词」。

- 子弹窗开着的时候，点父弹窗的任何地方（包括释义文字）都是先**收起它上面的子弹窗**、回到这一层；收起之后再点父弹窗里的词，才会查新词。这样不会因为手滑在下面一层点了一下就丢掉正在看的那一层。
- MDX 词典释义里自带的交叉引用链接（「→ 参见某词」那种）点了也是在弹窗里重新查那个词，不会把弹窗导航到别的页面。
- 在首页查词页、剪贴板查词这类独立查词界面里，弹窗顶栏还有「后退」「前进」按钮，可以在查过的词之间来回翻。
- 电脑上的全局查词（应用外查词卡片）同样支持嵌套，见[能不能在任何软件里查词](/faq/global-lookup)。

唯一的例外是「悬停即查词」：悬停最多只触发一层弹窗，否则鼠标在释义上划过就会连环弹出一串。要在弹窗里继续查，用点击。

## 加号制卡：一点就是一张 Anki 卡

连好 Anki 之后（见[怎么连接 Anki](/faq/anki)），词条旁的**加号**就是制卡按钮。一张卡会自动带上：词头、读音、释义、单词发音、音调、词频，以及你查词时所在的**原句**、截图或视频片段、原声——具体哪些进哪个字段，由 **设置 → 制卡 → 字段映射** 决定，用 Fushi 一键创建的 Lapis 卡组不用自己配。

几个容易忽略的细节：

- **想用某一本词典的释义当主释义**：长按那本词典的标题，标题会变成主题色加粗，表示选中。这时制卡，主释义字段用的就是它，而不是排第一的那本。
- **这个词已经在 Anki 里**：加号会变成 ✓。再点它会弹出选择：覆写哪一张已有的卡、在 Anki 中打开、新增为重复卡，或者取消。
- **原句不对 / 想多带一句**：弹窗里的「调整上下文」会打开「选择句子上下文」：可以前加一句、后加一句、编辑句子，有音频的还能试听，确认后再制卡。也可以先把几句「加入制卡句子」，攒好再做成一张卡。
- **Anki 没开**：卡不会丢，会进待发送队列，下次连上自动送过去。

第一次做卡的完整流程见[第一张卡怎么做](/faq/first-card)；Anki 那边的设置建议见[连上 Anki 之后该怎么设置](/faq/anki-basics)。

## 键盘、鼠标、手柄怎么操作弹窗

- **鼠标滚轮**滚动弹窗；**Alt + 滚轮**跳到上一个 / 下一个词条。滚动速度在 设置 → 查词 → 词条内容 的「弹窗滚轮速度」里调。
- 「查词弹窗」这组快捷键（鼠标位于查词弹窗上时生效）里有「播放单词发音」「制卡（加号）」「上一个词条」「下一个词条」，都可以在 **设置 → 快捷键设置** 里改键。
- 手柄默认用方向键上下切换词条。
- 手机上可以在弹窗上滑动关闭；能不能滑动关闭、滑动灵敏度和「弹窗关闭动画」都在 设置 → 查词 → 弹窗窗口 里。

## 弹窗太大、太小、挡字怎么办

**设置 → 查词 → 弹窗窗口**：

- **查词窗口最大宽度 / 最大高度**：调弹窗尺寸；桌面端直接拖弹窗右下角也会改这两个值。小说、漫画、视频共用这一组。
- **底部停靠查词弹窗**：不跟着被查的字走，固定成屏幕底部一条整宽面板。可以按场景分开开（小说中 / 漫画中 / 视频中 / 游戏中底部停靠）。手机竖屏读小说时很好用。
- **查词弹窗瞬时滚动**：给墨水屏用，弹窗按固定距离跳动、不放滚动动画。
- 竖排小说里，弹窗会放在当前这一列的左边或右边，尽量不压住正在读的那一列。

## 常见状况

- **点了没反应 / 弹窗是空的**：先确认词典已导入且没被隐藏；在首页查词页输入一个常见词试试，查不到就是词典问题。
- **结果总是一个字**：多半点在了词的中间或词尾，点词头的第一个字；也可能是缺少这类词的词典。
- **弹窗里的字太小**：弹窗顶栏有放大 / 缩小查词字号的按钮，设置里也有「词典字号」。
- **同一个词好几本词典内容重复**：把不常看的词典往后排并折叠，见[怎么导入词典](/faq/dictionaries)。
