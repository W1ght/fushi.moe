同一本 EPUB，換個字型、調大一點行距，讀起來的累不累差別很大。Fushi 閱讀器的排版選項都能在讀書時當場調，改完正文立刻按新樣式重排，不用退出書。這篇按「方向 → 字型 → 間距 → 振假名 → 主題和書籍樣式」逐項說明，設定名都和 app 裡一致。

## 在哪裡調

- **讀書時**：點正文空白處喚出控制欄，點 **閱讀設定**。面板分幾頁：**主題與字型**（主題、正文字型、字型大小、字型粗細、振假名）、**排版**（模式、方向、行高、邊距、進階選項）、**翻頁與手勢**、**有聲書**、**查詞**。面板裡有一段日文示例文字做預覽，調的時候能直接看到效果。
- **不在書裡時**：**設定 → 閱讀**，「模式與排版方向」和「排版」兩組是同一批設定。

這些都是閱讀器的全域性設定，所有書共用一套。

## 豎排還是橫排

**閱讀設定 → 排版 → 常用 → 排版方向**：「豎排」或「橫排」。預設是豎排，從右往左讀，和日本文庫本一致；讀橫排的網路小說、英文書或者不習慣豎排時切成橫排。切換時閱讀位置不會丟。

豎排有幾項專屬的細節調整，在 **排版 → 進階選項** 裡（切到橫排時自動隱藏）：

- **文字方向**：豎排裡夾著的英文字母和數字怎麼擺。「混合」（預設）讓半形字母橫躺著順著行走，「豎直」讓每個字母都立起來，和漢字一樣一個個往下排。
- **字偶間距（縱排）**：啟用字型自帶的豎排字距調整，標點和小假名擠得更緊湊。
- **VPAL 縱排替代**：啟用字型的豎排比例寬度字形，假名疏密更自然。只有字型本身帶這些 OpenType 功能時才看得出差別。

翻頁、滾動、視覺小說三種模式都能和豎排、橫排任意組合，見[三種閱讀模式怎麼選？](/faq/reader-modes.zh-HK)。

## 字型、字號和粗細

**正文字型**：點進去是全 app 共用的**字型庫**，可以：

- **匯入字型檔案**：選本機的 TTF / OTF 等字型檔案；
- **從 URL 匯入**：貼上字型檔案的下載地址；
- **新增系統字型**：直接用電腦上已經裝好的字型；
- **推薦字型**：幾款常用的中日文字型，點一下下載。

每一款字型可以勾選「字型用途」——「小說正文字型」「詞典字型」「影片字幕字型」等互不干擾；多款字型拖拽排列優先順序，排前面的優先用，缺字時才往後找。預設是「預設（書籍自帶 / 系統字型）」，也就是不強行指定，用 EPUB 自己宣告的字型，沒有就用系統字型。

字型鏈還跟**內容語言**有關：同一個漢字，日文、簡體中文、繁體中文的標準字形不一樣，Fushi 按書的語言挑字型。EPUB 裡聲明瞭語言就自動用它；宣告錯了或者沒宣告，在書架上長按這本書，選「內容語言」手動指定。全域性的預設值在 **設定 → 外觀與互動 → 排版 → 預設內容語言**。

**字型大小**：8–128，預設 22。手機上一般 18–24 比較舒服，平板和電腦可以更大。**字型粗細**：100–900，預設 400（正常），螢幕偏淡或者字型太細時調到 500–600。

## 行高、段落和邊距

- **行高**：1–3 倍，預設 1.65。豎排時就是列與列之間的距離；書帶振假名時行高太小注音會擠，建議不低於 1.6。
- **段落間距**：段與段之間額外空出的距離，0–3em，預設 0。
- **段落縮排**：段首縮排幾個字，預設 0（用書自帶的縮排）。
- **兩端對齊**：讓每一行左右（豎排時上下）都對齊到邊緣。
- **上 / 下 / 左 / 右邊距**：按螢幕百分比算，預設左右各 2%、上下 0。手機上想多放字就調小，平板想留白就調大。
- **每頁列數**：只在翻頁模式下出現，預設「自動」，寬屏上可設成 2 列。

## 振假名（注音）

日文書裡漢字上方的小字讀音（ruby）怎麼顯示，在 **閱讀設定 → 主題與字型 → 隱藏振假名**，四個選項：

- **關閉**（預設）：不隱藏，振假名原樣顯示；
- **點選顯示**：振假名預設藏起來但位置保留（行距不跳），點一個詞只揭開這個詞的讀音，這一下不觸發查詞——適合先自己猜讀音、再核對；
- **隱藏**：完全不顯示振假名；
- **淡顯**：照常顯示，但顏色變淡，不搶正文的視線，深淺主題下都有效。

還有一個快捷鍵「切換振假名」（預設綁在手柄右搖桿按下 R3，鍵盤沒有預設鍵，可以自己綁，見[快捷鍵與手柄](/faq/shortcuts-gamepad.zh-HK)）：「點選顯示」時一次揭開 / 收回整頁注音，「淡顯」時臨時恢復全亮；「關閉」和「隱藏」時按了沒有效果。查詞本身不依賴振假名——即使隱藏了注音，點詞照樣能查到讀音。

## 主題、書籍樣式和插圖

- **主題**：白色、米黃、護眼、水藍、灰暗、深暗、純黑，晚上讀用深暗或純黑（OLED 屏更省電）。
- **優先書籍樣式**：預設開，尊重 EPUB 自帶的 CSS（標題樣式、特殊排版）。書的樣式和你的設定打架時（比如書裡寫死了字號）關掉它，以你的設定為準。還不滿意的話，在書架長按這本書選「編輯書籍 CSS」直接改這本書的樣式表，改壞了可以「全部重置」。
- **圖片模糊（防劇透）**：插圖先模糊顯示，點一下才揭開，避免翻頁時被彩插劇透。
- **將插圖頁併入正文**：預設開，把只有一張圖的單獨章節併到相鄰的正文裡連續顯示，不再單獨佔一頁。

## 常見狀況

- **改了字型沒變化**：先看「優先書籍樣式」是否開著、書的 CSS 是否寫死了字型；再看字型庫裡這款字型有沒有勾「小說正文字型」、排序是不是在前面。
- **豎排裡的數字橫躺著不好看**：把「文字方向」改成「豎直」。
- **振假名和上一行重疊**：調大行高。
- **中日文混排的字形看著像簡體中文**：書的內容語言被識別錯了，長按書選「內容語言」改成日語。
