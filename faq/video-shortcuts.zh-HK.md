用影片學語言，和單純看劇最大的區別是**你經常要回頭**：這句沒聽清，再聽一遍；這個詞不認識，停下來查；這句值得做卡，倒回去截。普通播放器只有「快退 10 秒」，來回拖進度條非常打斷節奏。Fushi 的播放器按「句」來操作——字幕的每一句就是一個單位，跳句、重播、自動暫停都以句為準。

下面按用途分組列出最常用的操作和預設按鍵（Windows / Linux 鍵盤為準；macOS 上 Ctrl 組合鍵換成 Command；Android / iOS 接外接鍵盤時同樣生效）。所有按鍵都能改，見最後一節。

## 逐句跳轉和重播本句

這是看番學日語用得最多的一組：

| 操作 | 預設鍵 | 手柄 |
|---|---|---|
| 上一句字幕 / 下一句字幕 | Ctrl+← / Ctrl+→ | X / Y |
| 重播當前句 | R | LT |
| 重播上一句 | Shift+R | — |
| 快退 / 快進 | ← / →（或 A / D、J / I） | LB / RB、十字鍵左右 |
| 上一章 / 下一章（影片帶章節時） | PageUp / PageDown | — |
| 上一幀 / 下一幀 | , / . | — |

- **重播當前句**會回到這一句的開頭重新播放，是練聽力、跟讀（shadowing）最順手的鍵：聽不清就按 R，再聽不清再按 R。
- **快退 / 快進**的步長在 **設定 → 影片 → 控制與手勢 →「快進/快退步長（秒）」** 裡改，預設 3 秒。
- 播放器底欄的「上一句字幕」「下一句字幕」按鈕在沒有字幕時會退化成按步長快退快進，有字幕時按句跳。
- 手機上沒有鍵盤時：**雙擊快進**（雙擊畫面左右兩側快退快進，預設關閉，在「控制與手勢」裡開啟）、左右滑動調進度，以及把「重播本句」等按鈕放到播放器上（播放器按鈕佈局可以自定義）。

## 每句說完自動暫停

**字幕暫停播放模式**開啟後，每一句字幕播完就自動暫停，給你時間看字幕、查詞、跟讀，然後按空格繼續。適合精聽：一句一句往下走，不會一不留神就過去三句。

開關在 **設定 → 影片 → 字幕行為與來源** 裡，播放器的設定面板字幕分組裡也有同一個開關，看到一半隨時開關。和「重播當前句」配合是經典用法：自動停 → 沒聽懂按 R → 聽懂了按空格。

想練純聽力時反過來，把字幕先藏起來：**B** 切換字幕模糊，**Shift+B** 在「不遮蔽 → 模糊 → 隱藏」之間迴圈，**H** 直接隱藏主字幕；副字幕對應 **Shift+G** 迴圈、**Shift+H** 隱藏。分階段怎麼用見[怎麼用副字幕（雙語）過渡](/faq/secondary-subtitle.zh-HK)。

## 字幕列表：整集臺詞一覽、搜尋、收藏

按 **L**（手柄 **Start**）開啟字幕列表，整集每一句臺詞按時間排開，當前句高亮：

- 點一句的文字**直接查詞**；關掉「點字幕文字查詞（關閉後點字幕只跳轉）」後，點一句只跳到這句；也可以用選單裡的「跳到此句」；
- **Ctrl+F** 搜尋字幕，輸入就篩選臺詞——想找「剛才那句帶『やっぱり』的」時很好用；
- **Ctrl+D** 收藏當前句，列表頂部切到「收藏」只看收藏過的句子，還能「匯出收藏語句」；
- 「自動滾動」讓列表跟著播放走；字號可以放大縮小。

字幕列表是複習一集內容的好地方：看完一集開啟列表從頭掃一遍，挑幾句值得的[制卡](/faq/sentence-mining.zh-HK)。

## 倍速：放慢聽清，加速過水

| 操作 | 預設鍵 |
|---|---|
| 加速 / 減速 | ] 或 = / [ 或 - |
| 速度復位（回到 1.0×） | Backspace |
| 按住臨時倍速 | 按住 E |

- 每按一次變化的幅度是 **設定 → 影片 → 控制與手勢 →「倍速步進」**，預設 0.1；播放器上的倍速按鈕也能直接選 0.5×–2.0× 之間的檔位。
- **按住臨時倍速**：按住 E 期間用加速檔播放，鬆開回到原速，適合快速跳過沒有對白的段落。手機上對應的是**長按畫面**，速度在「長按倍速」裡設，預設 2.0×。
- 剛起步聽不清時放到 0.8×–0.9× 很有幫助，但別一直慢放——儘早回到 1.0×，正常語速才是你最終要聽懂的。

## 不用滑鼠查詞、對軸和其它常用鍵

**鍵盤 / 手柄查詞**：按 **Enter**（手柄 **Select**）進入字幕選詞游標，方向鍵移動到要查的詞，Enter 查詞，Esc 退出。另有「下一個詞（掃詞）」「上一個詞（掃詞）」兩個動作，預設不綁鍵，想用的話在快捷鍵設定裡自己配。

**字幕時間對不上**：**Z / X** 字幕延遲減小 / 增大（每次 100 ms），**Ctrl+Shift+←** 把上一句字幕對齊到當前時間、**Ctrl+Shift+→** 把下一句對齊到當前時間（聽到這句開口時按一下就對上），**Shift+A** 開啟字幕波形對軸。詳見[字幕和畫面對不上怎麼辦](/faq/subtitle-sync.zh-HK)。

**其它**：

| 操作 | 預設鍵 | 手柄 |
|---|---|---|
| 播放 / 暫停 | 空格、P | A |
| 返回上一級 / 退出 | Esc | B |
| 音量 + / − | ↑ / ↓（或 0 / 9） | 十字鍵上下 |
| 靜音 | M | — |
| 切換全屏 | F、F12 | RT |
| 截圖 / 截圖（含字幕） | S / Shift+S | — |
| 切換小窗 / 小窗控制元件 | W / Shift+M | — |
| 切換沉浸鎖定 | Shift+L | — |

**沉浸鎖定**會鎖住播放器，防止誤觸；鎖定後還允許哪些操作（比如查詞）在 **設定 → 影片 → 控制與手勢 →「沉浸模式」** 裡定。

## 一套順手的精聽 / 泛聽組合

鍵記不住沒關係，先記住下面兩套，夠用一大半場景：

**精聽一集（每句都要弄懂）**：開啟「字幕暫停播放模式」→ 每句停下後先讀一遍字幕，不認識的詞點一下查詞 → 沒聽清按 **R** 重聽，必要時 **[** 放慢一檔再聽 → 值得做卡的句子在查詞浮層裡點加號，或先 **Ctrl+D** 收藏、看完在字幕列表的「收藏」裡統一處理 → 按空格去下一句。這樣走一遍比正常看慢好幾倍，挑自己最喜歡、最想吃透的幾集來做。

**泛聽追番（享受劇情為主）**：關掉自動暫停，正常速度往下看；只在真的卡住時按 **Ctrl+←** 退回上一句、或者點一下字幕查詞；沒有對白的段落按住 **E** 快速帶過。看完再開啟字幕列表掃一遍，挑兩三句做卡就夠了。

兩種方式交替用：大部分時間泛聽保證輸入量，偶爾拿一集精聽打磨細節。為什麼輸入量比「每個詞都弄懂」更重要，見[什麼是可理解輸入](/faq/comprehensible-input.zh-HK)。

## 改鍵與手柄

所有影片快捷鍵都在 **設定 → 系統與關於 → 快捷鍵設定** 裡，可以改鍵、綁手柄按鍵；macOS、Windows / Linux 和手機各有一套按平臺調整過的預設值。手柄的預設對映按「遙控器」思路設計：A 播放 / 暫停、B 返回、LB / RB 與十字鍵左右快退快進、十字鍵上下音量、X / Y 上一句 / 下一句、LT 重播當前句、RT 全屏、Start 字幕列表、Select 進入選詞游標。整個 App 的手柄用法見[快捷鍵和手柄怎麼設定](/faq/shortcuts-gamepad.zh-HK)。
