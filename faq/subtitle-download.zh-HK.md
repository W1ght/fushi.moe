看番學日語，字幕是一切的前提：有日語字幕才能點詞查詞、一句一句制卡。生肉影片大多不帶日語字幕，需要另外找一份外掛字幕配上。Fushi 把「找字幕 → 下載 → 按集配對 → 對時間軸」這一整串做進了播放器，不用自己去網站上翻、下載、解壓、改檔名。

這篇講怎麼用、有哪些來源、各自要什麼配置，以及下載後時間對不上時怎麼辦。實在哪裡都找不到日語字幕，最後還可以[用語音識別自己生成一份](/faq/asr-subtitles.zh-HK)。

## 先配好字幕來源

字幕來源統一在 **設定 → 線上服務 → 字幕來源** 裡配置，目前有四家：

| 來源 | 擅長 | 需要什麼 |
|---|---|---|
| **Jimaku** | 動漫與日語真人影視的日語字幕，學日語首選 | 免費 API key：註冊或登入 Jimaku 後在賬號頁面（jimaku.cc/account）生成，填進來 |
| **OpenSubtitles** | 電影、劇集的多語種字幕 | 應用已內建 API 金鑰，開箱可用；可選登入自己的賬號用個人下載額度，也可以填自己的 key；可以用逗號寫想要的語言程式碼，如 `ja,en` |
| **SubDL** | 電影與劇集的英文及多語種字幕，按 IMDb / TMDB id 匹配 | 免費 API key（subdl.com/panel/api）；下載按 IP 計匿名每日額度 |
| **AJATT** | 免費日語字幕庫（kitsunekko 映象） | 什麼都不用，預設開著；字幕檔案從 GitHub 下載 |

每一家都有獨立開關，關掉後即使填了 key 也不再搜它。同一頁還有 **預設字幕語言**：預設跟隨影片自身的語言（音軌 / 刮削到的資料），選定某個語言則始終優先它——學日語就把它設成日語，搜出來的結果會把日語排在前面。

API 憑據不會隨備份匯出；如果你用 [Fushi 互聯](/faq/interconnect.zh-HK)，可以隨互聯同步到已配對裝置，在另一臺裝置上不用再填一遍。

## 在播放器裡搜一集的字幕

1. 開啟這一集，進播放器的 **字幕** 選單，點 **線上搜尋字幕**，進入全屏的字幕工作臺，作用域選 **本集**。
2. 番劇名、集數會按片名和刮削結果預填好，不對就改：**番劇名**寫作品名（日文、英文、羅馬字都可以試），**集數（可選）**留空就列出全部集。
3. Jimaku 會先在 AniList 上確認是哪個**系列**，避免同名不同季混在一起；確認不了時會提示「下面是按標題直接搜出來的結果，可能混入同系列其他季」。
4. 點 **查詢字幕**，在下面挑一個來源條目，再在結果裡選一個檔案下載。結果可以按 **語言**、**型別** 篩選，也能在 **篩選結果（如 WEBRip、BD）** 裡輸入關鍵詞按版本過濾。
5. 下載完自動掛到這一集並選中，字幕軌列表裡會出現這條外掛字幕，點詞就能查。

小提示：同一部番在字幕站上經常同時有 **BD 版**和 **WEB 版**兩套時間軸，挑和你影片同版本的那套能省掉大部分對軸工作（[怎麼看資源名](/faq/release-names.zh-HK)）。字幕組釋出的**整季包**也能直接用：Fushi 會從包裡按集號拆出這一集；ZIP 包可以直接解，RAR / 7z 包暫不支援解包，需要到網站下載後手動解壓，再用 **匯入字幕檔案…** 掛上。

## 整季批次下載：一次配好一整部

追一整部番時沒必要一集一集搜。在字幕工作臺裡把作用域切到 **整個合集**（媒體庫裡合集的右鍵選單、合集詳情頁也有 **為合集獲取字幕** 入口）：

- 先繫結系列、挑一個字幕來源，Fushi 按檔名裡的集號把每一集和字幕檔案對上，整季打包的字幕會自動拆分；
- 點 **下載全部**，逐集下載並掛好，完成後提示「字幕已獲取：x/y」；
- **合集字幕設定** 裡可以給這部作品單獨設 **預設字幕語言**（留空 = 跟隨影片自身語言）和 **偏好版本**——批次下載優先選這個版本，整季共用一套時間軸，不會一集 BD 一集 WEB。

## 不想手動找：自動配字幕

兩條自動路徑，都只在你配置好字幕來源後生效：

- **番劇下載時附帶字幕**：用 Fushi [下載番劇](/faq/anime-download.zh-HK)時選「附帶字幕」，下載完成後自動到 Jimaku 匹配日語字幕並逐集配對。
- **刮削後自動補字幕**：**設定 → 影片 → 字幕行為與來源** 裡的「刮削後自動補字幕」開著時，[刮削](/faq/scraping.zh-HK)完成後仍然沒有字幕的影片會自動從已配置的線上字幕來源取一條。它**絕不覆蓋已有字幕**。

## 下載的字幕時間對不上：按內嵌字幕對齊

外掛字幕不是給你手上這個影片檔案做的，早幾秒晚幾秒很常見。很多影片本身帶一條文本字幕軌（哪怕是英文或中文的），它的開口時刻和這個影片是嚴格對齊的，Fushi 就拿它當參照：

- **自動**：同一頁的 **下載字幕自動對齊**（預設開）——按影片自帶的字幕軌給下載的字幕對時間軸，只在證據充分時才改，否則保持原樣；
- **手動**：播放時字幕選單裡點 **按內嵌字幕對齊**。對得上就另存一份對好時間的新字幕（原字幕不動）；結果不太確定時會彈窗給出建議平移量讓你決定；對不上（不是這一集、剪輯不同）會提示並保持原樣；
- 這條字幕是下載時自動對齊過的，再點這個按鈕會提供 **恢復原始字幕**，把原始時間軸恢復成一份新字幕。

影片沒有可當參考的文本字幕軌時，用調軸滑條、**自動對軸**、**波形對軸**，或 **用語音模型重定時** 逐句修正，詳見[字幕和畫面對不上怎麼辦](/faq/subtitle-sync.zh-HK)。

## 常見狀況

- **點了搜尋提示「未配置字幕來源」或「線上字幕來源都已關閉」**：去 **設定 → 線上服務 → 字幕來源** 至少開啟一家。只想先試試的話，AJATT 和 OpenSubtitles 不用填任何東西。
- **提示某家「拒絕了 API key」**：key 填錯或已失效，回到那一家的設定裡重新生成、貼上。
- **「沒有找到第 N 集字幕」**：先清空集數看全部結果——有的字幕檔案沒標集號，會提示「另有 x 個未標集號檔案可嘗試」；也可以換番劇名的寫法（日文原名 / 英文名）或換個來源。
- **搜到的是別的季**：在系列一欄改選正確的那一季，或在番劇名里加上季數。
- **想同時掛中文當參考**：下載一條中文字幕當副字幕，見[怎麼用副字幕（雙語）過渡](/faq/secondary-subtitle.zh-HK)。
- **本地已經有字幕檔案**：同目錄、同名的外掛字幕會自動識別；不同名的用字幕選單裡的 **匯入字幕檔案…** 手動掛。各種字幕格式的區別見[字幕格式有哪些](/faq/subtitle-formats.zh-HK)。
