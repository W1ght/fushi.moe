看番学日语，字幕是一切的前提：有日语字幕才能点词查词、一句一句制卡。生肉视频大多不带日语字幕，需要另外找一份外挂字幕配上。Fushi 把「找字幕 → 下载 → 按集配对 → 对时间轴」这一整串做进了播放器，不用自己去网站上翻、下载、解压、改文件名。

这篇讲怎么用、有哪些来源、各自要什么配置，以及下载后时间对不上时怎么办。实在哪里都找不到日语字幕，最后还可以[用语音识别自己生成一份](/faq/asr-subtitles)。

## 先配好字幕来源

字幕来源统一在 **设置 → 在线服务 → 字幕来源** 里配置，目前有四家：

| 来源 | 擅长 | 需要什么 |
|---|---|---|
| **Jimaku** | 动漫与日语真人影视的日语字幕，学日语首选 | 免费 API key：注册或登录 Jimaku 后在账号页面（jimaku.cc/account）生成，填进来 |
| **OpenSubtitles** | 电影、剧集的多语种字幕 | 应用已内置 API 密钥，开箱可用；可选登录自己的账号用个人下载额度，也可以填自己的 key；可以用逗号写想要的语言代码，如 `ja,en` |
| **SubDL** | 电影与剧集的英文及多语种字幕，按 IMDb / TMDB id 匹配 | 免费 API key（subdl.com/panel/api）；下载按 IP 计匿名每日额度 |
| **AJATT** | 免费日语字幕库（kitsunekko 镜像） | 什么都不用，默认开着；字幕文件从 GitHub 下载 |

每一家都有独立开关，关掉后即使填了 key 也不再搜它。同一页还有 **默认字幕语言**：默认跟随视频自身的语言（音轨 / 刮削到的资料），选定某个语言则始终优先它——学日语就把它设成日语，搜出来的结果会把日语排在前面。

API 凭据不会随备份导出；如果你用 [Fushi 互联](/faq/interconnect)，可以随互联同步到已配对设备，在另一台设备上不用再填一遍。

## 在播放器里搜一集的字幕

1. 打开这一集，进播放器的 **字幕** 菜单，点 **在线搜索字幕**，进入全屏的字幕工作台，作用域选 **本集**。
2. 番剧名、集数会按片名和刮削结果预填好，不对就改：**番剧名**写作品名（日文、英文、罗马字都可以试），**集数（可选）**留空就列出全部集。
3. Jimaku 会先在 AniList 上确认是哪个**系列**，避免同名不同季混在一起；确认不了时会提示「下面是按标题直接搜出来的结果，可能混入同系列其他季」。
4. 点 **查找字幕**，在下面挑一个来源条目，再在结果里选一个文件下载。结果可以按 **语言**、**类型** 筛选，也能在 **筛选结果（如 WEBRip、BD）** 里输入关键词按版本过滤。
5. 下载完自动挂到这一集并选中，字幕轨列表里会出现这条外挂字幕，点词就能查。

小提示：同一部番在字幕站上经常同时有 **BD 版**和 **WEB 版**两套时间轴，挑和你视频同版本的那套能省掉大部分对轴工作（[怎么看资源名](/faq/release-names)）。字幕组发布的**整季包**也能直接用：Fushi 会从包里按集号拆出这一集；ZIP 包可以直接解，RAR / 7z 包暂不支持解包，需要到网站下载后手动解压，再用 **导入字幕文件…** 挂上。

## 整季批量下载：一次配好一整部

追一整部番时没必要一集一集搜。在字幕工作台里把作用域切到 **整个合集**（媒体库里合集的右键菜单、合集详情页也有 **为合集获取字幕** 入口）：

- 先绑定系列、挑一个字幕来源，Fushi 按文件名里的集号把每一集和字幕文件对上，整季打包的字幕会自动拆分；
- 点 **下载全部**，逐集下载并挂好，完成后提示「字幕已获取：x/y」；
- **合集字幕设置** 里可以给这部作品单独设 **默认字幕语言**（留空 = 跟随视频自身语言）和 **偏好版本**——批量下载优先选这个版本，整季共用一套时间轴，不会一集 BD 一集 WEB。

## 不想手动找：自动配字幕

两条自动路径，都只在你配置好字幕来源后生效：

- **番剧下载时附带字幕**：用 Fushi [下载番剧](/faq/anime-download)时选「附带字幕」，下载完成后自动到 Jimaku 匹配日语字幕并逐集配对。
- **刮削后自动补字幕**：**设置 → 视频 → 字幕行为与来源** 里的「刮削后自动补字幕」开着时，[刮削](/faq/scraping)完成后仍然没有字幕的视频会自动从已配置的在线字幕来源取一条。它**绝不覆盖已有字幕**。

## 下载的字幕时间对不上：按内嵌字幕对齐

外挂字幕不是给你手上这个视频文件做的，早几秒晚几秒很常见。很多视频本身带一条文本字幕轨（哪怕是英文或中文的），它的开口时刻和这个视频是严格对齐的，Fushi 就拿它当参照：

- **自动**：同一页的 **下载字幕自动对齐**（默认开）——按视频自带的字幕轨给下载的字幕对时间轴，只在证据充分时才改，否则保持原样；
- **手动**：播放时字幕菜单里点 **按内嵌字幕对齐**。对得上就另存一份对好时间的新字幕（原字幕不动）；结果不太确定时会弹窗给出建议平移量让你决定；对不上（不是这一集、剪辑不同）会提示并保持原样；
- 这条字幕是下载时自动对齐过的，再点这个按钮会提供 **恢复原始字幕**，把原始时间轴恢复成一份新字幕。

视频没有可当参考的文本字幕轨时，用调轴滑条、**自动对轴**、**波形对轴**，或 **用语音模型重定时** 逐句修正，详见[字幕和画面对不上怎么办](/faq/subtitle-sync)。

## 常见状况

- **点了搜索提示「未配置字幕来源」或「在线字幕来源都已关闭」**：去 **设置 → 在线服务 → 字幕来源** 至少打开一家。只想先试试的话，AJATT 和 OpenSubtitles 不用填任何东西。
- **提示某家「拒绝了 API key」**：key 填错或已失效，回到那一家的设置里重新生成、粘贴。
- **「没有找到第 N 集字幕」**：先清空集数看全部结果——有的字幕文件没标集号，会提示「另有 x 个未标集号文件可尝试」；也可以换番剧名的写法（日文原名 / 英文名）或换个来源。
- **搜到的是别的季**：在系列一栏改选正确的那一季，或在番剧名里加上季数。
- **想同时挂中文当参考**：下载一条中文字幕当副字幕，见[怎么用副字幕（双语）过渡](/faq/secondary-subtitle)。
- **本地已经有字幕文件**：同目录、同名的外挂字幕会自动识别；不同名的用字幕菜单里的 **导入字幕文件…** 手动挂。各种字幕格式的区别见[字幕格式有哪些](/faq/subtitle-formats)。
