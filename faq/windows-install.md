Windows 版只有一种推荐装法：到[下载页](/zh-cn/download)点 Windows 那一行的「下载」，拿到 `fushi-<版本>-windows-setup.exe`，双击安装。下载页对这一行的说明是「含 Galgame 语音挖掘、桌面划词」——Galgame 文本 / 语音捕获只在 Windows 上有，其他平台没有。

## 安装包和免安装 zip 选哪个？

**现在只发安装包。** 下载页以前有过一行「Windows（免安装）」，对应解压即用的 `-windows-x64.zip`（不建快捷方式、不注册文件关联、也不会自动更新），后来已经下掉，GitHub Releases 里现在的版本也只有 `-windows-setup.exe`。所以不用纠结，装安装包就行。

安装包本身已经很「轻」，多数人担心的几件事它都不做：

- **不需要管理员权限**。安装器按当前用户安装（不弹 UAC），程序默认装到 `%LOCALAPPDATA%\Fushi`，注册表只写当前用户这一侧。
- **不抢默认播放器**。「文件关联」那一步只是把 Fushi 加进 mkv / mp4 等视频的右键「打开方式」，安装器原话是「这些选项不会更改你的默认播放器」。
- **桌面快捷方式可以不要**。「创建桌面快捷方式」默认勾选，取消即可；之后的自动更新不会把它重新建回来，也不会挪动你已经摆好的图标位置。

如果你是从改名前的 Hibiki 升级上来的，直接装新的安装包即可，会原地升级，数据会自动迁移过来。

## 安装步骤

1. 在[下载页](/zh-cn/download)选「正式版」（日常推荐）或「调试版」（最新功能先到这里，区别见[正式版和调试版有什么区别？](/faq/channels)），点 Windows 行的「下载」。下载页会在浏览器里从多个来源分段并发拉取，拼好后做 SHA-256 校验，显示「SHA-256 校验通过」才说明文件完整；下载慢或失败见[下载很慢或者打不开怎么办？](/faq/download)。
2. 双击 `setup.exe`。安装向导是简体中文界面，依次是：选安装位置 →（仅全新安装）选**数据存储位置** → 选快捷方式和文件关联 → 开始安装。
3. 勾上最后一页的「启动 Fushi」，第一次打开会自动进入新手引导，按引导选功能、装推荐包、连 Anki 就能用了，详见[新手引导中途关掉了，怎么重新打开？](/faq/onboarding)。

## 程序装在哪，数据又存在哪？

这是两件事，安装器也是分开问的：

- **安装位置**放的是程序本身，体积不大。
- **数据存储位置**放的是书、漫画、封面、字幕、词典和数据库——安装器提示「这些数据可能远大于程序本身，建议选一个空间充足的位置」。默认是「文档」下的 `Fushi` 文件夹。推荐包（日语词典 + 发音音频库）就有约 9.5 GB，C 盘紧张的话这一步直接选到别的盘。

这一页**只在全新安装时出现**；升级、重装或应用内自动更新都不会再问，也不会动你已有的书库。装好之后想搬家，去 **设置 → 存储 → 数据存储位置** 里迁移，Fushi 会连同数据库里记录的路径一起改好，不要自己手动剪切文件夹。数据是不是只存在本机、会不会上传，见[我的数据存在哪里？会上传吗？](/faq/data)。

卸载时（Windows「设置 → 应用」里卸载 Fushi）删的是程序目录，你的数据存储位置不在程序目录里，想彻底清掉要自己去删那个文件夹——删之前确认有没有需要的备份。

## 弹出「Windows 已保护你的电脑」（SmartScreen）怎么办？

Fushi 的 Windows 安装包和程序文件在发布流程里会做代码签名。SmartScreen 除了看签名，还会看这个文件被多少人下载过；每个新版本刚发出来时下载量为零，偶尔仍可能弹出蓝色的「Windows 已保护你的电脑」。这不代表文件有问题：

1. 先确认文件是从 fushi.moe 下载页或 [GitHub Releases](https://github.com/hajisensai/Fushi/releases) 拿的，下载页显示过「SHA-256 校验通过」。
2. 点提示里的「更多信息」，再点「仍要运行」。

杀毒软件误报也是同理：Galgame 捕获组件（随安装包一起装在程序目录的 `voice_hook` 下）需要往游戏进程里注入 DLL，这类行为偶尔会被安全软件盯上。只有在你要用 Galgame 捕获时它才会运行，被拦了可以把 Fushi 的安装目录加进杀软白名单。

## 系统要求和常见坑

- **64 位 Windows**：安装包是 x64 版，建议 Windows 10 / 11。阅读器、查词弹窗等界面用的是系统的 Edge WebView2 组件，Windows 10 / 11 一般已经自带。
- **自动更新**：Fushi 会自己检查更新，**设置 → 系统与关于** 的「更新设置」里可以切「更新通道」、选「首选下载源」、手动「检查更新」，打开「自动安装更新」后发现新版会自动下载、静默安装，再重新打开 Fushi（不会重启电脑）。通道怎么选见[正式版和调试版有什么区别？](/faq/channels)。
- **更新时提示组件被占用**：如果你正开着游戏并用着 Galgame 捕获，更新会提示「Galgame 捕获组件被占用」，先关掉游戏再更新。播放器组件 `libmpv-2.dll` 被占用时，按提示关掉残留的 Fushi 进程，实在不行重启一次 Windows 再装。
- **装到网络盘或移动硬盘**：数据存储位置可以选外接盘，但启动时那块盘没接上，Fushi 会卡在加载界面并提示你；点「重试」会用默认位置启动这一次，原位置的数据不会被动。常年插着的盘才适合这样用。
- **换电脑**：在旧电脑 **设置 → 同步与备份** 里导出一份备份，新电脑装好 Fushi 后导入；也可以开云备份或[互联备份](/faq/interconnect)，省得每次手动拷文件。
- **手机和平板**：同一份书库想在手机上看，用 [Fushi 互联](/faq/interconnect)让 Windows 电脑当主机，不用在每台设备上重复导入。

其他平台的装法见 [Android 怎么安装 Fushi？](/faq/android-install)、[macOS 怎么安装 Fushi？](/faq/macos-install)，各平台差异总览见[支持哪些平台？](/faq/platforms)。
