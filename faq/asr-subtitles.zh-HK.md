看番學日語，最理想的組合是「生肉 + 日語字幕」：字幕能點詞、能制卡，卡上帶這一句的原聲和畫面。可不少影片根本找不到日語字幕——冷門老番、日劇、綜藝、YouTube 下下來的訪談、自己錄的課程。Fushi 的辦法是讓裝置自己「聽」一遍：用本機的語音識別（ASR）模型把整集臺詞轉成一份帶時間軸的文字字幕，之後就和普通外掛字幕一樣用。

先說結論：**能做，全部在你的裝置上跑，不上傳任何音訊**；代價是第一次要下載模型、轉一集要花一些時間，準確度比不上人工字幕。找得到現成字幕時，先去[找現成的字幕](/faq/subtitle-download.zh-HK)，那個更快也更準；找不到再轉錄。

## 在播放器裡一鍵生成字幕

1. 開啟影片，進播放器的 **字幕** 選單（字幕軌那一組）。
2. 點 **語音識別生成字幕**（副標題寫著「生成可查詞、制卡的文字字幕」）。
3. 彈出的 **裝置端語音轉錄** 面板裡：
   - **語音語言**：選影片裡說的語言，看番就選日語。選錯語言轉出來是亂碼，這是最常見的失敗原因；
   - **模型**：每種語言預設給一個模型，下拉里寫著它是「專用模型 · 這門語言識別最準」還是「通用模型」、適合手機還是桌面、要下多大；
   - **加速**：預設「自動（有 GPU 則用）」，也可以選「僅 CPU」。
4. 模型沒下載時點 **下載模型**，下完點 **開始轉錄**。面板上顯示進度、已用時間、預計剩餘時間和相對即時的倍速。
5. 轉完後這份字幕會作為外掛字幕自動掛上並選中，字幕軌列表裡多出一條。點字幕上的詞就能查，點加號就能[制卡](/faq/first-card.zh-HK)。

轉錄中途可以點 **暫停**，進度存在檢查點上，之後回來點 **繼續轉錄** 接著跑，不用從頭再來。轉出來的字幕按集儲存，下次開啟這一集還在。

入口在哪些影片上出現：本地影片檔案都有；通過 [Fushi 互聯](/faq/interconnect.zh-HK)看另一臺裝置上的影片時也有——由那臺主機把整集音軌裁出來傳給你，再在本機轉錄。純網路流（直鏈、YouTube、線上影片源）拿不到完整音軌，沒有這個入口。

## 模型要下多大、放在哪

模型按語言分包，只下你要用的那門語言：

- **日語**用 ReazonSpeech 的 k2-v2 模型，是日語專用模型。手機和沒有可用顯示卡的電腦跑的是 int8 量化版，整套約 160 MB；Windows 上有可用的 GPU 時會用 fp32 版，編碼器本身就有約 590 MB。
- **英語、普通話、粵語、韓語、俄語、越南語、泰語**各有一個專用模型。
- **德語、西班牙語、法語、義大利語、荷蘭語、葡萄牙語、土耳其語、印尼語、阿拉伯語**共用一個通用多語言模型（Omnilingual，約 1 GB 級別），覆蓋廣但單語言精度不如專用模型，面板裡會標「大模型 · 建議桌面（有獨顯更好）」。

已下載的模型在 **設定 → 儲存 → 語音識別模型** 裡管理：每種語言顯示「已下載 · 佔用 xx」「未下載 · 需要 xx」或「已下載一部分」，不用的可以刪掉釋放空間，下次轉錄這種語言時再自動提示下載。模型檔案下壞了讀不出來時，Fushi 會自動清掉並提示重新下載。

會自己折騰模型的使用者，面板裡還有 **手動指定模型…**：選一個放著 sherpa-onnx 匯出模型的資料夾（encoder / decoder / joiner 三件套，或單個 CTC 模型，外加 tokens.txt），檔案留在原處不復制。

## 轉一集要多久

取決於裝置和加速方式，大致規律：

- **Windows + 獨立顯示卡**：自動模式會用 GPU（DirectML）跑 fp32 模型，這是最快的組合；面板上會寫「運行於 …」告訴你實際用的是 GPU 還是 CPU，GPU 不可用時會提示已回退到 CPU；
- **macOS / 沒有顯示卡的 Windows / Linux**：自動模式走 int8 + CPU，速度夠用；macOS 上加速裡另有一個 **CoreML（FP32）** 選項，實測在日語模型上不一定比 CPU 快，預設不用它；
- **Android / iOS**：日語輕量模型手機也能跑，但慢不少，也更耗電發熱，建議插著電、放著讓它跑。通用多語言大模型在手機上會標「大模型 · 手機上能跑，但很慢」。

面板上的「$speed 倍速」就是當前速度相對音訊時長的倍數，看一眼就知道要等多久。

在 iOS 26 / macOS 26 上，模型列表裡還會多一個 **系統語音識別（Apple）**：用系統自帶的語音模型，不下 Fushi 那份模型，但系統第一次用某種語言時仍會下它自己的語言資產（由系統保管、多個 app 共用）。這個引擎在檔案中途沒法暫停，停止會丟掉當前檔案的進度。

## 準確度怎麼樣、哪些情況會差

語音識別不是人工聽寫，期望要放對：

- **對白清楚、BGM 不吵**的段落（日常番、日劇、訪談、播客式內容）準確度高，日常詞彙基本都對，拿來點詞制卡完全夠用；
- **背景音樂和音效很重**的段落（戰鬥、OP / ED、插入曲）容易漏句或出錯字；
- **多人同時說話、喊叫、方言、口齒含糊**的臺詞也會差一些；
- 人名、專有名詞、生造詞經常寫成同音的別的字——這類詞查詞本來就查不到，影響不大；
- 歌曲部分基本不要指望。

幾條實用建議：

- **語言一定選對**，選錯是最常見的「轉出來全是亂碼」原因；
- 雙語音軌的藍光 / 劇場版，先在播放器裡切到日語音軌再轉錄，Fushi 轉的是當前選中的那條音軌；
- 制卡前看一眼字幕裡這句和你聽到的是否一致，有錯字就在卡片編輯裡改掉再存，別把識別錯誤背進腦子裡；
- 轉出來的字幕時間軸是按語音切的句，句子長短和人工字幕不同，這是正常的。

## 已經有字幕、只是時間對不上？用「重定時」

如果你手裡有一份日語字幕，只是和這個影片版本的時間對不上（BD 與 WEB 剪輯不同、幀率不同導致越往後越偏），不需要整份重新轉錄。字幕選單裡的 **用語音模型重定時** 會聽一遍這一集，用識別結果當參照逐句修正時間，**正文和順序一個字不動**，結果另存成一份新字幕，原檔案不改。只有很少句子對上時會提示「檢查語音語言是否選對、這份字幕是不是這一集的」。更多對軸辦法見[字幕和畫面對不上怎麼辦](/faq/subtitle-sync.zh-HK)。

## 有聲書也能用同一套轉錄

同一套裝置端轉錄也用在有聲書上：匯入有聲書時字幕來源可以選「裝置端轉錄生成字幕」，轉出來的字幕用來和正文對齊、逐句高亮，見[有聲書怎麼用](/faq/audiobook.zh-HK)。

還沒裝 Fushi 的話，從[下載頁](/zh-hk/download)獲取，Android、iOS、Windows、macOS（Apple Silicon）和 Linux 都支援裝置端轉錄。
