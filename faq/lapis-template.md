在 Fushi 里点加号制卡时，卡片并不是随便拼出来的一段文字，而是按一个叫 **Lapis** 的 Anki 笔记类型（卡片模板）把各种素材分别填进不同字段。弄明白哪个字段放什么，你才知道卡片为什么长这样、想改的时候该改哪里。前置步骤（装 Anki、连上 Fushi）见[怎么连接 Anki](/faq/anki)，做出第一张卡见[装好之后怎么边看番边制卡](/faq/first-card)。

## Lapis 是什么？

Lapis 是一个开源的 Anki 笔记类型，作者是 Ruri、itokatsu 和 kuri（GitHub 上的 donkuri/lapis），以 GPL-3.0 发布，专为「查词制卡」这种用法设计：一张卡里同时有单词、读音、释义、例句、句子音频和图片，复习时正面只给你最少的提示，翻过去才是完整信息。

Fushi 内置的是 Lapis **1.7.0** 的正面、背面和样式表原文，只在此之上追加了一小段修样式问题的 CSS（比如音调标签框过宽、旧卡片里释义列表缩进过大），不改上游的结构。

创建方法：**设置 → 制卡** 里点 **「创建并选用 Lapis」**——它会向 Anki 添加一个叫 Lapis 的笔记类型和一个叫 Lapis 的牌组，并直接选为制卡目标；新手引导里配置 Anki 的那一步也会带你做这件事。如果 Anki 里已经有 Lapis，Fushi 会提示「Lapis 笔记类型和卡组已存在，已选中」，不会重复创建。

你自己装过 Lapis 也行：只要笔记类型名字里含「lapis」，或者同时有 `Expression`、`MainDefinition`、`Sentence` 三个字段，Fushi 就会把它当作 Lapis，给**还没映射的字段**套上默认映射；你已经手动映射过的字段保持不动。

## Fushi 制卡时每个字段放什么？

下面是 Fushi 给 Lapis 的出厂字段映射。左边是 Anki 字段名，右边是 Fushi 的占位符（在 **设置 → 制卡 → 字段映射** 里能看到同样的写法）：

| Lapis 字段 | 占位符 | 放进去的东西 |
|---|---|---|
| Expression | `{expression}` | 词条本身（词典形，如「食べる」） |
| ExpressionFurigana | `{furigana-plain}` | 带振假名的词条 |
| ExpressionReading | `{reading}` | 读音 |
| ExpressionAudio | `{audio}` | **单词音频**：来自你装的单词音频库 |
| SelectionText | `{popup-selection-text}` | 你在查词弹窗里划选的那段文字 |
| MainDefinition | `{glossary-first}` | **主释义**：你在弹窗里长按选中了哪本词典就用哪本，没选就用排第一的那本 |
| Sentence | `{sentence}` | **原句**：这个词所在的那句台词 / 那句话，目标词加粗 |
| SentenceAudio | `{sentence-audio}` | **句子音频**：视频里这句台词的原声，或有声书里这一句 |
| Picture | `{card-image}` | **卡片图片**：视频是截图或动图，书是封面 |
| Glossary | `{glossary}` | 全部词典的释义 |
| PitchPosition | `{pitch-accent-positions}` | 音调位置（需要装音调词典） |
| PitchCategories | `{pitch-accent-categories}` | 音调类型（平板、头高等） |
| Frequency | `{frequencies}` | 各本词频词典给出的词频 |
| FreqSort | `{frequency-harmonic-rank}` | 汇总后的词频排名，给「按词频重排新卡」用 |
| MiscInfo | `{source-link} {clip-timestamp}` | **来源**：作品标题（可跳回 Fushi 里的原位置）+ 片段时间 |
| IsWordAndSentenceCard | `x` | 卡型开关，见下一节 |

**故意留空的字段**：DefinitionPicture、SentenceFurigana、Hint、IsClickCard、IsSentenceCard、IsAudioCard。SentenceFurigana 留空是 Lapis 官方的建议（句子注音会让你在正面就看到读音）；另外三个 `Is…` 是卡型开关，一次只该填一个。

几点补充：

- **图片是截图还是动图**：在 **设置 → 制卡 → 制卡媒体** 的「视频卡片图片」里选：「制卡时截图」「字幕开头截图」「动图 GIF（字幕片段）」或「带声音的视频片段」。动图格式可选 AVIF、WebP、GIF；「图片 / GIF 清晰度」「音频质量」也在这里。
- **带声音的视频片段**需要笔记类型能播放视频：在同一页的「视频播放适配」里给 Lapis 打上适配。没适配时 Fushi 会改用 GIF + 音频，并提示「当前笔记类型未适配视频」。在 iPhone 上用 AnkiMobile 复习的话，「视频片段格式」请选 MP4（WebM 在 AnkiMobile 里放不了）。
- **句子音频被切掉开头或结尾**：调「句子音频开头余量」「句子音频结尾余量」，它们不会越过上一句或下一句。
- **一句台词跨了好几条字幕**：在字幕列表里多选再制卡，原句和句子音频按整段截。
- **音调和词频字段是空的**：多半是没装对应的词典；新手引导里的[推荐包](/faq/pack)带了日语的音调和词频词典。

## Lapis 的五种卡型怎么切？

Lapis 用几个开关字段决定正面显示什么。规则是：**最多给其中一个字段填任意内容（习惯上填 `x`），其余留空**。

| 填了哪个开关 | 正面显示 |
|---|---|
| 全部留空 | **单词卡**：只有词 |
| IsWordAndSentenceCard（Fushi 默认） | **单词 + 句子卡**：词，下面以提示的形式放原句 |
| IsSentenceCard | **句子卡**：整句，考你读懂整句 |
| IsClickCard | **点击卡**：先显示词，点一下（或按 C）切到原句 |
| IsAudioCard | **音频卡**：显示原句并播放句子音频，句中加粗的目标词被替换成 [...] |

Fushi 默认用「单词 + 句子」：正面不放发音，只有词和它所在的句子，这样复习时练的是「在真实语境里看到这个词能不能想起读音和意思」。为什么正面不放发音见 [Anki 怎么用](/faq/anki-basics)。

要换卡型，到 **设置 → 制卡 → 字段映射**，点对应字段，在输入框里填 `x` 或清空即可（这个对话框既能从列表里选占位符，也能直接输入文字，所以 MiscInfo 那种把两个占位符拼在一起的写法也是在这里写的）。注意字段映射只影响**之后**制的卡；已经在 Anki 里的卡要在 Anki 的浏览器里改字段。

## 怎么在 Fushi 里改 Lapis 卡片的样式？

**设置 → 制卡 → Lapis 卡片样式** 是一个不用写 CSS 的编辑器（只在 AnkiConnect 和 AnkiDroid 下出现；AnkiMobile 不支持修改笔记类型，所以 iPhone 上没有这一项）：

- **可视化编辑**：上面是 Lapis 卡片预览，可以切正面 / 背面；点预览里的任意部分（单词、读音、例句、释义框、首要释义……）就选中它，下面调字号、文字颜色、背景高亮、粗体、对齐、行高、内外边距、边框和圆角。
- **布局**：复用 Lapis 自带的布局开关，桌面与手机 Anki 同时生效——「图片位置」（单词左侧 / 单词右侧 / 例句内）、「例句位置」（释义框上方 / 下方）、「音频按钮」（读音旁 / 例句内 / 固定在底部）。
- **自定义区域**：把已有字段摆到卡片的其它位置（卡片顶部、单词区下方、例句下方、释义框下方、卡片底部）。只改显示，不新增也不删除 Anki 字段。
- **卡片字号缩放**、**自定义 CSS**、**高级 CSS**：整体缩放字号，或者直接追加自己的 CSS（写在样式表里受保护的用户区段）。

改完点 **「应用样式到 Anki」**才会写进 Anki，写之前会自动备份。如果 Fushi 发现 Anki 里的 Lapis 模板被手动改过，会先弹「Anki 端模板有改动」问你要不要覆盖。改坏了有三条退路：**「备份 Lapis 模板」**手动存一份、**「从备份恢复」**、**「恢复出厂 Lapis」**（用内置版本覆盖样式和正反面模板，并重置字号、自定义 CSS 和自定义区域；卡片数据不受影响）。

## 不用 Lapis 可以吗？

可以。在 **设置 → 制卡** 里选别的牌组和笔记类型，再到「字段映射」给每个字段挑占位符——上面表格里的占位符对任何笔记类型都可用，另外还有「文档标题」「字幕例句」等。但要注意：

- 笔记类型的**第一个字段**必须映射，否则 Anki 会拒收（提示「所选笔记类型的第一个字段为空」）；
- 换了笔记类型之后，旧的映射一个都对不上时，Anki 同样会拒收这张卡，要重新映射；
- 「Lapis 卡片样式」编辑器只认 Lapis；别的模板要在 Anki 里自己改样式。

拿不准就用 Lapis：它是 Fushi 默认的模板，出厂映射开箱即用，「按词频重排新卡」能直接用它的 FreqSort 字段，样式编辑器和备份 / 恢复也只为它准备。
