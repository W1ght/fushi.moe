漫画是日语学习里最容易坚持的材料之一：画面帮你猜意思，对话短、口语多，一卷读下来词汇量涨得很明显。问题在于漫画是图片，字没法直接选中——Fushi 的做法是先用 **漫画 OCR** 把对话框里的字识别出来，叠一层看不见的文字在图上，之后就能像读电子书一样点字查词、制卡。这篇讲手里已经有漫画文件时怎么导进来、怎么识别、怎么制卡；在线追更的漫画见[怎么在线看漫画并识别文字制卡？](/faq/manga-online)。

本地导入和阅读在所有平台都可用，包括 iOS（iOS 版按 App Store 规定只是没有在线漫画源）。

## Fushi 支持哪些漫画格式？

漫画库认的「一卷」可以是下面这些东西，判断以文件内容为准，不只看扩展名：

- **图片文件夹**：一个文件夹装一卷的页图，支持 JPG / JPEG / PNG / WebP / GIF / BMP。
- **CBZ / ZIP**：页图打包的压缩包。`.zip` 和 Yomitan 词典包同一个扩展名，Fushi 会打开包看里面装的是不是页图再决定按漫画导入。
- **CBR / RAR / CB7**：需要 7-Zip 解包。Windows 安装包自带；macOS / Linux 要系统里装了 `7z` 或 `7za`（在 PATH 上）。手机上导不了的话，先在电脑上转成 CBZ 或解成图片文件夹。
- **PDF**：扫描版漫画常常就是一份 PDF，漫画库会逐页渲染成页图导入。注意：同一份 PDF 从书架导入的话会当成 PDF 书进 PDF 阅读器，想当漫画读要从漫画库导入。
- **EPUB（扫描版）**：只装着页图的 EPUB 也能当漫画导入；有正文文字的普通 EPUB 应该去书架导入，见[电子书阅读器](/faq/epub-reader)。
- **.mokuro**：mokuro 工具产出的 OCR 结果文件，连同它的页图一起导入就直接带字，不用再识别，见[mokuro 是什么？](/faq/mokuro)。

如果你在书架上误导入了一个漫画压缩包，Fushi 会弹「这看起来是漫画」，点 **按漫画导入** 就转到漫画流程。

## 怎么导入：单卷、批量、长期扫描

入口在底栏 **漫画** → 顶部的 **导入** 子标签。这里有三个按钮：

1. **导入漫画**：弹出导入对话框，可以「选择漫画文件」或「选择漫画文件夹」，也可以直接把文件拖进对话框（桌面端）。单卷时可以填标题，不填就用文件名。
2. **导入文件夹**：选一个文件夹后会问去向——**设为常驻来源**（以后自动扫描此文件夹里的新漫画，适合你一直往里放新卷的目录）或 **仅导入这一次**。
3. **网络**：添加 SFTP / FTP / WebDAV 远端书架作为来源，适合漫画放在 NAS 上的情况。

批量导入的规则：如果你选的文件夹本身没有页图，但里面直接放着一批 CBZ / ZIP / EPUB / .mokuro 之类的整卷文件，Fushi 会提示「该文件夹里有 N 个整卷文件，将逐卷各导入为一本，书名取各自的文件名」，导完报告成功、跳过、失败各几卷。文件夹里既有页图又有整卷文件时，按页图文件夹处理。

## 导入时顺便识别：OCR 导入向导

导入对话框底部有一个 **OCR 导入漫画** 按钮，打开的是 OCR 向导：选一个图片文件夹，可选填标题，然后两个选择——

- **开始 OCR**：先整卷识别再入库，进度显示「第 x / y 页」；
- **直接导入**：不识别，先入库，以后在阅读器里再识别。

向导里有 **OCR 设置** 按钮直达识别引擎设置，刚下好模型回来就能选。如果文件夹里已经有 `.mokuro` 文件，向导会提示直接用普通导入；已经入库的书再跑向导叫「识别本卷文字」，每页都已有识别结果时会提示无需再跑（重跑会覆盖）。

## 打开后识别文字、点字查词

第一次用本地识别要下模型：**设置 → 漫画 → 漫画 OCR**，选好「本机 OCR 模型」后点 **下载模型**；应用内下载不通时用 **导入本地模型**，把自己下载的文件（或包含它们的 zip）导进来。模型和引擎怎么选，详见[漫画 OCR 认不准怎么办？](/faq/manga-ocr-tips)。注意出厂的「默认 OCR 引擎」是 **Google Lens**：它要联网、会把页面图片上传给 Google，识别前会先弹窗说明并请你同意，不同意就不会上传；不想上传就把引擎改成本地模型或「设备自带」。

识别有两种触发方式，在阅读器的 **阅读设置 → OCR** 里的「OCR 触发方式」：

- **打开即识别**：打开一卷就从当前页开始在后台识别整卷，右上角显示进度；
- **手动**：工具栏出现 **识别本卷** 按钮，想识别时再点。

识别结果写回这本漫画的数据（mokuro 同款格式），下次打开不用重跑。识别完之后：

- **点对话框里的字** 就弹词典，和电子书一样；
- 桌面端按住 **Shift** 移动鼠标可以悬停查词，打开「悬停查词」后不按 Shift 也行；
- 打开「显示识别范围」可以看到每个文字框的边界，方便判断是没识别到还是没点准。

## 制卡：卡上有什么？

查词弹窗里点加号就制卡，和其他媒体共用同一套 Anki 设置（还没连 Anki 先看[怎么连接 Anki？](/faq/anki)和[第一张卡](/faq/first-card)）：

- **句子**：用 OCR 几何重建出的整句——点的是哪个对话框，句子就是那个框里的话，而不是单个词；
- **图片**：你点中文字的那一页的画面。双页并排显示时，取的是文字实际所在的那一页，而不是左右两页里的第一页；
- 词、读音、释义等字段照常从词典来。

漫画没有原声，所以卡上没有句子音频；单词本身的发音可以照常加，见[单词发音](/faq/word-audio)。

## 阅读设置与常见问题

阅读器设置分「模式 / 滤镜 / OCR」几页，常用的有：**阅读方向**（日漫选「从右到左」）、**阅读模式**（翻页 / 条漫 / 纵向分页等）、**跨页偏移**（双页配对不对时改「封面独占」或「从第一页起配对」）、**宽页独占一屏**、**裁剪白边**、**拆分宽页**，还有亮度、对比度、反色、灰度等滤镜。设置可以按全局，也可以只对当前作品单独设。

- **导入后没有页**：检查文件夹里的图片格式是不是上面列的那几种；选错了层级（选了装着多个子文件夹的父目录）也会这样，改选具体那一卷的文件夹，或用批量导入。
- **CBR / RAR 导不进来**：桌面端装上 7-Zip（Windows 自带不用管），手机端先转 CBZ。
- **iOS 上选 .mokuro 没有页图**：iOS 单选 .mokuro 文件带不上旁边的页图，要选整卷文件夹（含 .mokuro 和它的页图文件夹），或打包成 .zip / .cbz 再导入。
- **点字没反应**：先确认这页识别过了（「显示识别范围」能看到框）；没有框就是还没识别或引擎没装好，「没有可用的 OCR 引擎」时去 漫画 OCR 设置里下载模型或换引擎。
