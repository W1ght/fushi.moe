漫畫是日語學習裡最容易堅持的材料之一：畫面幫你猜意思，對話短、口語多，一卷讀下來詞彙量漲得很明顯。問題在於漫畫是圖片，字沒法直接選中——Fushi 的做法是先用 **漫畫 OCR** 把對話方塊裡的字識別出來，疊一層看不見的文字在圖上，之後就能像讀電子書一樣點字查詞、制卡。這篇講手裡已經有漫畫檔案時怎麼導進來、怎麼識別、怎麼制卡；線上追更的漫畫見[怎麼線上看漫畫並識別文字制卡？](/faq/manga-online.zh-HK)。

本地匯入和閱讀在所有平臺都可用，包括 iOS（iOS 版按 App Store 規定只是沒有線上漫畫源）。

## Fushi 支援哪些漫畫格式？

漫畫庫認的「一卷」可以是下面這些東西，判斷以檔案內容為準，不只看副檔名：

- **圖片資料夾**：一個資料夾裝一卷的頁圖，支援 JPG / JPEG / PNG / WebP / GIF / BMP。
- **CBZ / ZIP**：頁圖打包的壓縮包。`.zip` 和 Yomitan 詞典包同一個副檔名，Fushi 會開啟包看裡面裝的是不是頁圖再決定按漫畫匯入。
- **CBR / RAR / CB7**：需要 7-Zip 解包。Windows 安裝包自帶；macOS / Linux 要系統裡裝了 `7z` 或 `7za`（在 PATH 上）。手機上導不了的話，先在電腦上轉成 CBZ 或解成圖片資料夾。
- **PDF**：掃描版漫畫常常就是一份 PDF，漫畫庫會逐頁渲染成頁圖匯入。注意：同一份 PDF 從書架匯入的話會當成 PDF 書進 PDF 閱讀器，想當漫畫讀要從漫畫庫匯入。
- **EPUB（掃描版）**：只裝著頁圖的 EPUB 也能當漫畫匯入；有正文文字的普通 EPUB 應該去書架匯入，見[電子書閱讀器](/faq/epub-reader.zh-HK)。
- **.mokuro**：mokuro 工具產出的 OCR 結果檔案，連同它的頁圖一起匯入就直接帶字，不用再識別，見[mokuro 是什麼？](/faq/mokuro.zh-HK)。

如果你在書架上誤匯入了一個漫畫壓縮包，Fushi 會彈「這看起來是漫畫」，點 **按漫畫匯入** 就轉到漫畫流程。

## 怎麼匯入：單卷、批次、長期掃描

入口在底欄 **漫畫** → 頂部的 **匯入** 子標籤。這裡有三個按鈕：

1. **匯入漫畫**：彈出匯入對話方塊，可以「選擇漫畫檔案」或「選擇漫畫資料夾」，也可以直接把檔案拖進對話方塊（桌面端）。單卷時可以填標題，不填就用檔名。
2. **匯入資料夾**：選一個資料夾後會問去向——**設為常駐來源**（以後自動掃描此資料夾裡的新漫畫，適合你一直往裡放新卷的目錄）或 **僅匯入這一次**。
3. **網路**：新增 SFTP / FTP / WebDAV 遠端書架作為來源，適合漫畫放在 NAS 上的情況。

批次匯入的規則：如果你選的資料夾本身沒有頁圖，但裡面直接放著一批 CBZ / ZIP / EPUB / .mokuro 之類的整卷檔案，Fushi 會提示「該資料夾裡有 N 個整卷檔案，將逐卷各匯入為一本，書名取各自的檔名」，導完報告成功、跳過、失敗各幾卷。資料夾裡既有頁圖又有整卷檔案時，按頁圖資料夾處理。

## 匯入時順便識別：OCR 匯入嚮導

匯入對話方塊底部有一個 **OCR 匯入漫畫** 按鈕，開啟的是 OCR 嚮導：選一個圖片資料夾，可選填標題，然後兩個選擇——

- **開始 OCR**：先整卷識別再入庫，進度顯示「第 x / y 頁」；
- **直接匯入**：不識別，先入庫，以後在閱讀器裡再識別。

嚮導裡有 **OCR 設定** 按鈕直達識別引擎設定，剛下好模型回來就能選。如果資料夾裡已經有 `.mokuro` 檔案，嚮導會提示直接用普通匯入；已經入庫的書再跑嚮導叫「識別本卷文字」，每頁都已有識別結果時會提示無需再跑（重跑會覆蓋）。

## 開啟後識別文字、點字查詞

第一次用本地識別要下模型：**設定 → 漫畫 → 漫畫 OCR**，選好「本機 OCR 模型」後點 **下載模型**；應用內下載不通時用 **匯入本地模型**，把自己下載的檔案（或包含它們的 zip）導進來。模型和引擎怎麼選，詳見[漫畫 OCR 認不準怎麼辦？](/faq/manga-ocr-tips.zh-HK)。注意出廠的「預設 OCR 引擎」是 **Google Lens**：它要聯網、會把頁面圖片上傳給 Google，識別前會先彈窗說明並請你同意，不同意就不會上傳；不想上傳就把引擎改成本地模型或「裝置自帶」。

識別有兩種觸發方式，在閱讀器的 **閱讀設定 → OCR** 裡的「OCR 觸發方式」：

- **開啟即識別**：開啟一卷就從當前頁開始在後臺識別整卷，右上角顯示進度；
- **手動**：工具欄出現 **識別本卷** 按鈕，想識別時再點。

識別結果寫回這本漫畫的資料（mokuro 同款格式），下次開啟不用重跑。識別完之後：

- **點對話方塊裡的字** 就彈詞典，和電子書一樣；
- 桌面端按住 **Shift** 移動滑鼠可以懸停查詞，開啟「懸停查詞」後不按 Shift 也行；
- 開啟「顯示識別範圍」可以看到每個文字框的邊界，方便判斷是沒識別到還是沒點準。

## 制卡：卡上有什麼？

查詞彈窗裡點加號就制卡，和其他媒體共用同一套 Anki 設定（還沒連 Anki 先看[怎麼連線 Anki？](/faq/anki.zh-HK)和[第一張卡](/faq/first-card.zh-HK)）：

- **句子**：用 OCR 幾何重建出的整句——點的是哪個對話方塊，句子就是那個框裡的話，而不是單個詞；
- **圖片**：你點中文字的那一頁的畫面。雙頁並排顯示時，取的是文字實際所在的那一頁，而不是左右兩頁裡的第一頁；
- 詞、讀音、釋義等欄位照常從詞典來。

漫畫沒有原聲，所以卡上沒有句子音訊；單詞本身的發音可以照常加，見[單詞發音](/faq/word-audio.zh-HK)。

## 閱讀設定與常見問題

閱讀器設定分「模式 / 濾鏡 / OCR」幾頁，常用的有：**閱讀方向**（日漫選「從右到左」）、**閱讀模式**（翻頁 / 條漫 / 縱向分頁等）、**跨頁偏移**（雙頁配對不對時改「封面獨佔」或「從第一頁起配對」）、**寬頁獨佔一屏**、**裁剪白邊**、**拆分寬頁**，還有亮度、對比度、反色、灰度等濾鏡。設定可以按全域性，也可以只對當前作品單獨設。

- **匯入後沒有頁**：檢查資料夾裡的圖片格式是不是上面列的那幾種；選錯了層級（選了裝著多個子資料夾的父目錄）也會這樣，改選具體那一卷的資料夾，或用批次匯入。
- **CBR / RAR 導不進來**：桌面端裝上 7-Zip（Windows 自帶不用管），手機端先轉 CBZ。
- **iOS 上選 .mokuro 沒有頁圖**：iOS 單選 .mokuro 檔案帶不上旁邊的頁圖，要選整卷資料夾（含 .mokuro 和它的頁圖資料夾），或打包成 .zip / .cbz 再匯入。
- **點字沒反應**：先確認這頁識別過了（「顯示識別範圍」能看到框）；沒有框就是還沒識別或引擎沒裝好，「沒有可用的 OCR 引擎」時去 漫畫 OCR 設定裡下載模型或換引擎。
