沉浸學習最容易讓人放棄的地方，是感覺不到進步。Fushi 會在後臺替你記賬：看了多少分鐘番、讀了多少字輕小說、查了多少個詞、做了多少張卡。這些數字不是用來攀比的，而是讓你看見「這週比上週多讀了兩萬字」「閱讀速度從每小時三千字漲到了四千」——這種進步靠感覺是察覺不到的。

所有統計都只存在你自己的裝置上，不註冊、不上傳（見[我的資料存在哪裡](/faq/data.zh-HK)）。

## 統計在哪裡看

- **首頁頂部工具欄 → 統計中心**（柱狀圖圖示），這是主入口。
- **閱讀器裡**：按 `I` 或從選單開啟「書內統計」，能看到本次閱讀、本章 / 全書還需多久讀完、本書累計的時長、字數、查詞和制卡數；點「開啟完整記錄」直接跳到統計中心的閱讀頁籤。
- 如果你在模組設定裡關掉了首頁：**設定 → 系統與關於 → 首頁入口 → 統計中心**。

統計中心頂部有四個頁籤：**總覽**、**閱讀**、**觀看**、**遊戲**。總覽把三個域加在一起，其餘三個各管一類媒體。

## 統計中心裡有什麼

四個頁籤用的是同一套佈局，從上往下：

1. **學習日曆**：按天上色的日曆，顏色越深學得越多；點某一天就切到那一天的資料。上面一行「過去一週」用火苗顯示近 7 天裡哪幾天有學習。
2. **範圍條**：選 **日 / 周 / 月 / 年 / 全部 / 自定義**，用「上一段 / 下一段」前後翻；翻到過去時會出現「今日 / 本週 / 本月 / 本年」一鍵回到當前。周按週一開始算；「自定義」可以任選起止日期。
3. **範圍時長圖**：所選範圍內每天（範圍很長時按周或按月）的學習時長柱狀圖。
4. **所選範圍**卡片：這段時間的 **字數**、**時長**、**活躍天數**、**查詞**、**制卡**、**收藏**（收藏的詞）、**收藏語句**；觀看頁另有「看完」的集數，遊戲頁另有遊玩「會話」數。閱讀相關的地方會顯示 **閱讀速度**（多少「字/時」）。
5. **分析**（閱讀、觀看頁的摺疊區）：閱讀頁有趨勢、速度摘要（加權均速、最快日 / 最慢日、典型日）、各來源（小說 / 漫畫 / PDF 各佔多少）；觀看頁有按小時的分佈。
6. **最近沉浸**：最近的學習會話列表，「全部會話」看完整歷史。
7. **按作品明細**：每本書、每部番、每個遊戲各學了多久、多少字，可以按時長、字數或速度排序；點一行進入這部作品自己的會話列表。

首頁的 **每日目標** 卡片可以「設定目標」（每日 / 每週字數，帶快捷預設和「近 7 日日均」參考），這個目標統計的是閱讀、影片字幕、遊戲臺詞三類加起來的字數。

## 各個數字是怎麼算的

知道口徑，才能正確解讀數字。

**閱讀時長（小說 / PDF / 漫畫）**

- 只有你真的在讀的時候才計時。長時間沒有翻頁、滾動等操作，就停止計入——這個時長在 **設定 → 閱讀 → 閱讀統計 → 空閒判定時長** 裡調，預設 10 分鐘。
- 切到別的應用、開啟選單或全屏面板時停表；查詞彈窗和制卡對話方塊不停表，它們本來就是閱讀的一部分。
- **閱讀計時開始方式**（同一分組）：**開啟即開始**（預設）、**翻頁後開始**（開啟書先不計，翻過第一頁或有聲書開始出聲才計）、**手動**。隨時可以用閱讀器裡的計時按鈕或 `P` 鍵暫停 / 繼續。

**閱讀字數 / 頁數**

- 一頁在你**翻走**的那一刻才計入「讀過」。開啟書掃一眼就關掉，不會算字數。
- 往回翻會撤回，再往前翻按並集恢復——同一頁來回看只算一次，跳過沒讀的部分不算。
- 所以「閱讀速度（字/時）」反映的是真實閱讀量。速度至少要攢夠 1 分鐘樣本才顯示。

**觀看時長（影片 / 番劇）**

- 按播放狀態計時：在播就算，暫停不算；切到別的視窗但影片還在播，照常計。
- **只計第一次看到的部分**：回放上一句、拖回去重看、第二天重看同一集，都不再計時；快進跳過的部分也不算。所以一集 24 分鐘的番，無論反覆聽幾遍，觀看時長最多就是 24 分鐘。精聽反覆回放是好習慣，但統計裡它不會被重複算。
- Jellyfin / Emby 等媒體伺服器和互聯遠端的影片也照樣統計。

**遊戲**

- Windows 上用文本 Hook 抓到的 Galgame 臺詞計入字數；遊玩時長按遊戲會話記錄，不滿 60 秒的不入庫。

**查詞數、制卡數、收藏**

- 在閱讀器、影片、遊戲裡查一次詞、做一張卡、收藏一個詞或一句話，都記到對應的媒體和日期上。

## 「今日」從幾點開始

熬夜到凌晨兩點看番，算今天還是昨天？在任意統計頁範圍條右側點 **統計設定**，設 **「今日」從幾點開始**（0–23 點整點，預設 0 點）。設成 4 點的話，凌晨 2 點的學習記到前一天。

注意：只有改設定之後寫入的記錄按新邊界歸日，已有的歷史不會重新分桶。

同一個彈窗裡還有 **清空統計**：清空當前頁籤那一類（在總覽裡則三類一起清）。清空統計不影響你收藏的詞、句子、做好的 Anki 卡和遊戲庫，但不可撤銷。

## 記錯了怎麼辦

- **刪掉一次誤計的會話**：在「最近沉浸」或作品的會話列表裡找到它，**刪除會話**——比如開著書去吃飯忘了關、又把空閒判定調得很長。
- **編輯會話**：可以改一次會話的日期（整次會話挪過去，時刻不變）和字數。
- **刪一部作品的統計**：「刪除統計資料」會刪掉該項的時長、字數與查詞 / 制卡統計，收藏的單詞和句子不受影響。
- 「清除全部會話」會清掉所有會話記錄，需要二次確認。

## 多裝置、多配置方案

- **配置方案（Profile）之間是隔離的**：切換到另一個 Profile，統計中心只顯示這個 Profile 的數字（統計設定裡會寫明「僅顯示配置 xxx 的統計」）。適合一臺裝置上學兩門語言、或家人共用。
- **用 Fushi 互聯**：「與已配對裝置共享」裡的 **共享統計**（閱讀與觀看時長、字數、查詞與制卡計數）預設開啟，手機和電腦的統計雙向合併（見[互聯教程](/faq/interconnect.zh-HK)）。
- **用雲同步**：**設定 → 同步與備份 → 同步內容 → 同步統計**。兩端要用同名的 Profile，統計才能對上。
- 遊戲的統計不出本機。
- 備份檔案裡也可以帶上統計資料，見[怎麼備份和遷移資料](/faq/backup.zh-HK)。
- 從 **Hoshi Reader** 遷移過來的話，「第三方匯入」可以把它的閱讀統計一起匯入。

## 怎麼用這些數字

幾個實用建議：

- **看趨勢，不看單日**：某天只看了 10 分鐘沒關係，看月檢視的柱狀圖是不是整體往上走。
- **閱讀速度是最好的進步指標**：同類難度的輕小說，字/時持續上漲，說明你的閱讀在變得自動化。
- **查詞數 ÷ 字數**大致反映內容對你的難度：同一部作品讀到後面查詞變少，是正常的進步；如果一直很高，可以考慮換更簡單的內容，見[可理解輸入](/faq/comprehensible-input.zh-HK)。
- **制卡數別貪多**：每天做多少卡合適，見[每天做多少張卡合適](/faq/cards-per-day.zh-HK)。
- 想和別人比一比，可以試試實驗性的排行榜（首頁工具欄的「排行榜」），註冊前不會上傳任何資料。
