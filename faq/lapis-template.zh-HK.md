在 Fushi 裡點加號制卡時，卡片並不是隨便拼出來的一段文字，而是按一個叫 **Lapis** 的 Anki 筆記型別（卡片模板）把各種素材分別填進不同欄位。弄明白哪個欄位放什麼，你才知道卡片為什麼長這樣、想改的時候該改哪裡。前置步驟（裝 Anki、連上 Fushi）見[怎麼連線 Anki](/faq/anki.zh-HK)，做出第一張卡見[裝好之後怎麼邊看番邊制卡](/faq/first-card.zh-HK)。

## Lapis 是什麼？

Lapis 是一個開源的 Anki 筆記型別，作者是 Ruri、itokatsu 和 kuri（GitHub 上的 donkuri/lapis），以 GPL-3.0 釋出，專為「查詞制卡」這種用法設計：一張卡里同時有單詞、讀音、釋義、例句、句子音訊和圖片，複習時正面只給你最少的提示，翻過去才是完整資訊。

Fushi 內建的是 Lapis **1.7.0** 的正面、背面和樣式表原文，只在此之上追加了一小段修樣式問題的 CSS（比如音調標籤框過寬、舊卡片裡釋義列表縮排過大），不改上游的結構。

建立方法：**設定 → 制卡** 裡點 **「建立並選用 Lapis」**——它會向 Anki 新增一個叫 Lapis 的筆記型別和一個叫 Lapis 的牌組，並直接選為制卡目標；新手引導裡配置 Anki 的那一步也會帶你做這件事。如果 Anki 裡已經有 Lapis，Fushi 會提示「Lapis 筆記型別和卡組已存在，已選中」，不會重複建立。

你自己裝過 Lapis 也行：只要筆記型別名字裡含「lapis」，或者同時有 `Expression`、`MainDefinition`、`Sentence` 三個欄位，Fushi 就會把它當作 Lapis，給**還沒對映的欄位**套上預設對映；你已經手動對映過的欄位保持不動。

## Fushi 制卡時每個欄位放什麼？

下面是 Fushi 給 Lapis 的出廠欄位對映。左邊是 Anki 欄位名，右邊是 Fushi 的佔位符（在 **設定 → 制卡 → 欄位對映** 裡能看到同樣的寫法）：

| Lapis 欄位 | 佔位符 | 放進去的東西 |
|---|---|---|
| Expression | `{expression}` | 詞條本身（詞典形，如「食べる」） |
| ExpressionFurigana | `{furigana-plain}` | 帶振假名的詞條 |
| ExpressionReading | `{reading}` | 讀音 |
| ExpressionAudio | `{audio}` | **單詞音訊**：來自你裝的單詞音訊庫 |
| SelectionText | `{popup-selection-text}` | 你在查詞彈窗裡劃選的那段文字 |
| MainDefinition | `{glossary-first}` | **主釋義**：你在彈窗里長按選中了哪本詞典就用哪本，沒選就用排第一的那本 |
| Sentence | `{sentence}` | **原句**：這個詞所在的那句臺詞 / 那句話，目標詞加粗 |
| SentenceAudio | `{sentence-audio}` | **句子音訊**：影片裡這句臺詞的原聲，或有聲書裡這一句 |
| Picture | `{card-image}` | **卡片圖片**：影片是截圖或動圖，書是封面 |
| Glossary | `{glossary}` | 全部詞典的釋義 |
| PitchPosition | `{pitch-accent-positions}` | 音調位置（需要裝音調詞典） |
| PitchCategories | `{pitch-accent-categories}` | 音調型別（平板、頭高等） |
| Frequency | `{frequencies}` | 各本詞頻詞典給出的詞頻 |
| FreqSort | `{frequency-harmonic-rank}` | 彙總後的詞頻排名，給「按詞頻重排新卡」用 |
| MiscInfo | `{source-link} {clip-timestamp}` | **來源**：作品標題（可跳回 Fushi 裡的原位置）+ 片段時間 |
| IsWordAndSentenceCard | `x` | 卡型開關，見下一節 |

**故意留空的欄位**：DefinitionPicture、SentenceFurigana、Hint、IsClickCard、IsSentenceCard、IsAudioCard。SentenceFurigana 留空是 Lapis 官方的建議（句子注音會讓你在正面就看到讀音）；另外三個 `Is…` 是卡型開關，一次只該填一個。

幾點補充：

- **圖片是截圖還是動圖**：在 **設定 → 制卡 → 制卡媒體** 的「影片卡片圖片」裡選：「制卡時截圖」「字幕開頭截圖」「動圖 GIF（字幕片段）」或「帶聲音的影片片段」。動圖格式可選 AVIF、WebP、GIF；「圖片 / GIF 清晰度」「音訊質量」也在這裡。
- **帶聲音的影片片段**需要筆記型別能播放影片：在同一頁的「影片播放適配」裡給 Lapis 打上適配。沒適配時 Fushi 會改用 GIF + 音訊，並提示「當前筆記型別未適配影片」。在 iPhone 上用 AnkiMobile 複習的話，「影片片段格式」請選 MP4（WebM 在 AnkiMobile 裡放不了）。
- **句子音訊被切掉開頭或結尾**：調「句子音訊開頭餘量」「句子音訊結尾餘量」，它們不會越過上一句或下一句。
- **一句臺詞跨了好幾條字幕**：在字幕列表裡多選再製卡，原句和句子音訊按整段截。
- **音調和詞頻欄位是空的**：多半是沒裝對應的詞典；新手引導裡的[推薦包](/faq/pack.zh-HK)帶了日語的音調和詞頻詞典。

## Lapis 的五種卡型怎麼切？

Lapis 用幾個開關欄位決定正面顯示什麼。規則是：**最多給其中一個欄位填任意內容（習慣上填 `x`），其餘留空**。

| 填了哪個開關 | 正面顯示 |
|---|---|
| 全部留空 | **單詞卡**：只有詞 |
| IsWordAndSentenceCard（Fushi 預設） | **單詞 + 句子卡**：詞，下面以提示的形式放原句 |
| IsSentenceCard | **句子卡**：整句，考你讀懂整句 |
| IsClickCard | **點選卡**：先顯示詞，點一下（或按 C）切到原句 |
| IsAudioCard | **音訊卡**：顯示原句並播放句子音訊，句中加粗的目標詞被替換成 [...] |

Fushi 預設用「單詞 + 句子」：正面不放發音，只有詞和它所在的句子，這樣複習時練的是「在真實語境裡看到這個詞能不能想起讀音和意思」。為什麼正面不放發音見 [Anki 怎麼用](/faq/anki-basics.zh-HK)。

要換卡型，到 **設定 → 制卡 → 欄位對映**，點對應欄位，在輸入框裡填 `x` 或清空即可（這個對話方塊既能從列表裡選佔位符，也能直接輸入文字，所以 MiscInfo 那種把兩個佔位符拼在一起的寫法也是在這裡寫的）。注意欄位對映隻影響**之後**制的卡；已經在 Anki 裡的卡要在 Anki 的瀏覽器裡改欄位。

## 怎麼在 Fushi 裡改 Lapis 卡片的樣式？

**設定 → 制卡 → Lapis 卡片樣式** 是一個不用寫 CSS 的編輯器（只在 AnkiConnect 和 AnkiDroid 下出現；AnkiMobile 不支援修改筆記型別，所以 iPhone 上沒有這一項）：

- **視覺化編輯**：上面是 Lapis 卡片預覽，可以切正面 / 背面；點預覽裡的任意部分（單詞、讀音、例句、釋義框、首要釋義……）就選中它，下面調字號、文字顏色、背景高亮、粗體、對齊、行高、內外邊距、邊框和圓角。
- **佈局**：複用 Lapis 自帶的佈局開關，桌面與手機 Anki 同時生效——「圖片位置」（單詞左側 / 單詞右側 / 例句內）、「例句位置」（釋義框上方 / 下方）、「音訊按鈕」（讀音旁 / 例句內 / 固定在底部）。
- **自定義區域**：把已有欄位擺到卡片的其它位置（卡片頂部、單詞區下方、例句下方、釋義框下方、卡片底部）。只改顯示，不新增也不刪除 Anki 欄位。
- **卡片字號縮放**、**自定義 CSS**、**高階 CSS**：整體縮放字號，或者直接追加自己的 CSS（寫在樣式表裡受保護的使用者區段）。

改完點 **「應用樣式到 Anki」**才會寫進 Anki，寫之前會自動備份。如果 Fushi 發現 Anki 裡的 Lapis 模板被手動改過，會先彈「Anki 端模板有改動」問你要不要覆蓋。改壞了有三條退路：**「備份 Lapis 模板」**手動存一份、**「從備份恢復」**、**「恢復出廠 Lapis」**（用內建版本覆蓋樣式和正反面模板，並重置字號、自定義 CSS 和自定義區域；卡片資料不受影響）。

## 不用 Lapis 可以嗎？

可以。在 **設定 → 制卡** 裡選別的牌組和筆記型別，再到「欄位對映」給每個欄位挑佔位符——上面表格裡的佔位符對任何筆記型別都可用，另外還有「文件標題」「字幕例句」等。但要注意：

- 筆記型別的**第一個欄位**必須對映，否則 Anki 會拒收（提示「所選筆記型別的第一個欄位為空」）；
- 換了筆記型別之後，舊的對映一個都對不上時，Anki 同樣會拒收這張卡，要重新對映；
- 「Lapis 卡片樣式」編輯器只認 Lapis；別的模板要在 Anki 裡自己改樣式。

拿不準就用 Lapis：它是 Fushi 預設的模板，出廠對映開箱即用，「按詞頻重排新卡」能直接用它的 FreqSort 欄位，樣式編輯器和備份 / 恢復也只為它準備。
