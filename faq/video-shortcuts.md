用视频学语言，和单纯看剧最大的区别是**你经常要回头**：这句没听清，再听一遍；这个词不认识，停下来查；这句值得做卡，倒回去截。普通播放器只有「快退 10 秒」，来回拖进度条非常打断节奏。Fushi 的播放器按「句」来操作——字幕的每一句就是一个单位，跳句、重播、自动暂停都以句为准。

下面按用途分组列出最常用的操作和默认按键（Windows / Linux 键盘为准；macOS 上 Ctrl 组合键换成 Command；Android / iOS 接外接键盘时同样生效）。所有按键都能改，见最后一节。

## 逐句跳转和重播本句

这是看番学日语用得最多的一组：

| 操作 | 默认键 | 手柄 |
|---|---|---|
| 上一句字幕 / 下一句字幕 | Ctrl+← / Ctrl+→ | X / Y |
| 重播当前句 | R | LT |
| 重播上一句 | Shift+R | — |
| 快退 / 快进 | ← / →（或 A / D、J / I） | LB / RB、十字键左右 |
| 上一章 / 下一章（视频带章节时） | PageUp / PageDown | — |
| 上一帧 / 下一帧 | , / . | — |

- **重播当前句**会回到这一句的开头重新播放，是练听力、跟读（shadowing）最顺手的键：听不清就按 R，再听不清再按 R。
- **快退 / 快进**的步长在 **设置 → 视频 → 控制与手势 →「快进/快退步长（秒）」** 里改，默认 3 秒。
- 播放器底栏的「上一句字幕」「下一句字幕」按钮在没有字幕时会退化成按步长快退快进，有字幕时按句跳。
- 手机上没有键盘时：**双击快进**（双击画面左右两侧快退快进，默认关闭，在「控制与手势」里打开）、左右滑动调进度，以及把「重播本句」等按钮放到播放器上（播放器按钮布局可以自定义）。

## 每句说完自动暂停

**字幕暂停播放模式**打开后，每一句字幕播完就自动暂停，给你时间看字幕、查词、跟读，然后按空格继续。适合精听：一句一句往下走，不会一不留神就过去三句。

开关在 **设置 → 视频 → 字幕行为与来源** 里，播放器的设置面板字幕分组里也有同一个开关，看到一半随时开关。和「重播当前句」配合是经典用法：自动停 → 没听懂按 R → 听懂了按空格。

想练纯听力时反过来，把字幕先藏起来：**B** 切换字幕模糊，**Shift+B** 在「不遮蔽 → 模糊 → 隐藏」之间循环，**H** 直接隐藏主字幕；副字幕对应 **Shift+G** 循环、**Shift+H** 隐藏。分阶段怎么用见[怎么用副字幕（双语）过渡](/faq/secondary-subtitle)。

## 字幕列表：整集台词一览、搜索、收藏

按 **L**（手柄 **Start**）打开字幕列表，整集每一句台词按时间排开，当前句高亮：

- 点一句的文字**直接查词**；关掉「点字幕文字查词（关闭后点字幕只跳转）」后，点一句只跳到这句；也可以用菜单里的「跳到此句」；
- **Ctrl+F** 搜索字幕，输入就筛选台词——想找「刚才那句带『やっぱり』的」时很好用；
- **Ctrl+D** 收藏当前句，列表顶部切到「收藏」只看收藏过的句子，还能「导出收藏语句」；
- 「自动滚动」让列表跟着播放走；字号可以放大缩小。

字幕列表是复习一集内容的好地方：看完一集打开列表从头扫一遍，挑几句值得的[制卡](/faq/sentence-mining)。

## 倍速：放慢听清，加速过水

| 操作 | 默认键 |
|---|---|
| 加速 / 减速 | ] 或 = / [ 或 - |
| 速度复位（回到 1.0×） | Backspace |
| 按住临时倍速 | 按住 E |

- 每按一次变化的幅度是 **设置 → 视频 → 控制与手势 →「倍速步进」**，默认 0.1；播放器上的倍速按钮也能直接选 0.5×–2.0× 之间的档位。
- **按住临时倍速**：按住 E 期间用加速档播放，松开回到原速，适合快速跳过没有对白的段落。手机上对应的是**长按画面**，速度在「长按倍速」里设，默认 2.0×。
- 刚起步听不清时放到 0.8×–0.9× 很有帮助，但别一直慢放——尽早回到 1.0×，正常语速才是你最终要听懂的。

## 不用鼠标查词、对轴和其它常用键

**键盘 / 手柄查词**：按 **Enter**（手柄 **Select**）进入字幕选词光标，方向键移动到要查的词，Enter 查词，Esc 退出。另有「下一个词（扫词）」「上一个词（扫词）」两个动作，默认不绑键，想用的话在快捷键设置里自己配。

**字幕时间对不上**：**Z / X** 字幕延迟减小 / 增大（每次 100 ms），**Ctrl+Shift+←** 把上一句字幕对齐到当前时间、**Ctrl+Shift+→** 把下一句对齐到当前时间（听到这句开口时按一下就对上），**Shift+A** 打开字幕波形对轴。详见[字幕和画面对不上怎么办](/faq/subtitle-sync)。

**其它**：

| 操作 | 默认键 | 手柄 |
|---|---|---|
| 播放 / 暂停 | 空格、P | A |
| 返回上一级 / 退出 | Esc | B |
| 音量 + / − | ↑ / ↓（或 0 / 9） | 十字键上下 |
| 静音 | M | — |
| 切换全屏 | F、F12 | RT |
| 截图 / 截图（含字幕） | S / Shift+S | — |
| 切换小窗 / 小窗控件 | W / Shift+M | — |
| 切换沉浸锁定 | Shift+L | — |

**沉浸锁定**会锁住播放器，防止误触；锁定后还允许哪些操作（比如查词）在 **设置 → 视频 → 控制与手势 →「沉浸模式」** 里定。

## 一套顺手的精听 / 泛听组合

键记不住没关系，先记住下面两套，够用一大半场景：

**精听一集（每句都要弄懂）**：打开「字幕暂停播放模式」→ 每句停下后先读一遍字幕，不认识的词点一下查词 → 没听清按 **R** 重听，必要时 **[** 放慢一档再听 → 值得做卡的句子在查词浮层里点加号，或先 **Ctrl+D** 收藏、看完在字幕列表的「收藏」里统一处理 → 按空格去下一句。这样走一遍比正常看慢好几倍，挑自己最喜欢、最想吃透的几集来做。

**泛听追番（享受剧情为主）**：关掉自动暂停，正常速度往下看；只在真的卡住时按 **Ctrl+←** 退回上一句、或者点一下字幕查词；没有对白的段落按住 **E** 快速带过。看完再打开字幕列表扫一遍，挑两三句做卡就够了。

两种方式交替用：大部分时间泛听保证输入量，偶尔拿一集精听打磨细节。为什么输入量比「每个词都弄懂」更重要，见[什么是可理解输入](/faq/comprehensible-input)。

## 改键与手柄

所有视频快捷键都在 **设置 → 系统与关于 → 快捷键设置** 里，可以改键、绑手柄按键；macOS、Windows / Linux 和手机各有一套按平台调整过的默认值。手柄的默认映射按「遥控器」思路设计：A 播放 / 暂停、B 返回、LB / RB 与十字键左右快退快进、十字键上下音量、X / Y 上一句 / 下一句、LT 重播当前句、RT 全屏、Start 字幕列表、Select 进入选词光标。整个 App 的手柄用法见[快捷键和手柄怎么设置](/faq/shortcuts-gamepad)。
