Fushi 裡所有「查詞」最後都落到同一個東西上：**查詞彈窗**。閱讀器、影片字幕、漫畫 OCR、Galgame 浮窗、首頁的查詞頁、電腦上的全域性查詞、瀏覽器擴充套件，彈出來的都是同一套彈窗——同樣的詞典順序、同樣的排版、同樣的加號制卡。學會一處，處處都會。

還沒裝詞典的話先看[怎麼匯入詞典](/faq/dictionaries.zh-HK)或者直接裝[推薦包](/faq/pack.zh-HK)；彈窗裡一片空白，九成是詞典還沒裝好。

## 怎麼觸發查詞：點選、懸停、Shift

| 在哪 | 怎麼查 |
|---|---|
| 閱讀器正文、影片 / 番劇字幕、漫畫 OCR 文字、Galgame 臺詞浮窗 | **點一下**那個詞 |
| 桌面端（Windows / macOS / Linux），開啟「懸停即查詞」後 | 滑鼠**停在**字上就查，不用點 |
| 瀏覽器擴充套件（任意網頁） | **按住 Shift** 移到詞上，見[瀏覽器裡怎麼查詞](/faq/browser-lookup.zh-HK) |
| 首頁的查詞頁 | 輸入或貼上一段文字，再點其中的詞 |

點的是**一個位置**，不是一個詞：Fushi 從你點的那個字開始往後取一段文字，交給詞典引擎做「最長匹配」——能匹配上的最長詞條排在最前面。所以點「食べられなかった」的「食」，結果會是「食べる」；點到「べ」上就只會從「べ」開始匹配。點詞頭的第一個字，結果最準。

幾個和觸發有關的設定，都在 **設定 → 查詞 → 查詞觸發**：

- **懸停即查詞**：滑鼠懸停在文字上即自動查詞，無需點選或按住 Shift；最多觸發一層彈窗。僅桌面端。預設關。
- **離開查詞即繼續播放**：影片裡懸停查詞後，滑鼠離開字幕和彈窗就自動關掉彈窗並繼續播放。預設開，只對懸停發起的查詞生效。
- **掃描非日文文本**：關掉後，選區遇到非日文字元就停，不會把旁邊的英文字母、數字一起吃進去。預設開。讀日語以外的語言時保持開著。
- **結果中的詞頭數量上限**：一次最多列多少個詞頭。調小彈窗更短，調大能看到更多「也可能是這個詞」的候選。

另外 **設定 → 查詞 → 朗讀與反饋** 裡的「查詞時暫停」（預設開）會在查詞時暫停影片 / 有聲書，關掉彈窗後繼續。

## 彈窗裡有什麼：多詞典、變形說明、音調、詞頻

一個詞條從上到下大致是：

1. **詞頭和讀音**，旁邊是**喇叭**（播放單詞發音）和**加號**（制卡）。
2. **變形說明標籤**：你點的是「食べられなかった」，詞條是「食べる」，中間會掛幾個小標籤說明它經過了哪些變形（可能態、否定、過去……）。有說明的標籤懸停可以預覽、點選可以釘住一段語法解釋。
3. **音調**：裝了音調詞典才有，讀音上畫高低線，後面跟著 `[0]`、`[2]` 這種數字，詳見[怎麼顯示日語音調](/faq/pitch-accent.zh-HK)。
4. **詞頻**：裝了詞頻詞典才有，顯示這個詞在各本詞頻表裡的排名，詳見[詞頻詞典是什麼](/faq/frequency.zh-HK)。
5. **各本釋義詞典**的釋義，按你在詞典管理裡排好的順序一本一本往下列。

詞典多了彈窗會很長，**設定 → 查詞 → 詞條內容** 裡有幾個開關專門治這個：

- **摺疊詞典顯示**（預設開）：每本詞典預設收起，點標題展開。配合「自動展開行數」，可以讓前一兩行詞典始終展開，後面的收起。
- **詞典最多列數（自動填充）**：寬屏上把詞典方框排成多列，窄屏會自動減少列數。
- **緊湊釋義**：釋義條目同行顯示、用「 | 」分隔，不再每條佔一行。
- **顯示錶達標籤**：顯示詞頭上的詞性 / 用法標籤。

詞典的順序、隱藏、單本摺疊在 **設定 → 查詞 → 詞典管理** 裡調；字型、顏色在「詞典樣式」裡改，每本詞典可以單獨設。

### 詞形還原：為什麼點變形後的詞也能查到原形

日語的動詞、形容詞變化很多，詞典裡只收原形。Fushi 的詞典引擎帶一套**詞形還原規則**：把你點到的那段文字按規則逐步倒推（なかった → ない → 否定前的形態 → 原形），再拿每一個候選去詞典裡找，找到的就排進結果，並把推導過程顯示成上面說的變形標籤。

不止日語。Fushi 內建了日語、英語、德語、法語、西班牙語、韓語、阿拉伯語、拉丁語等十幾種語言的還原規則；英語還單獨處理不規則變化和短語動詞（gave up → give up）。沒有還原規則的語言照樣能查，只是要點到原形才命中。可查的語言由你匯入的詞典決定，見[只能學日語嗎](/faq/languages.zh-HK)。

## 彈窗裡再點詞：遞迴查詞（巢狀彈窗）

釋義裡又冒出不認識的詞？**直接在彈窗裡點它**。Fushi 會在當前彈窗之上再疊一層新彈窗，查這個新詞；新彈窗裡還能接著點，一層一層往下鑽。這就是 Yomitan 使用者說的「遞迴查詞」。

- 子彈窗開著的時候，點父彈窗的任何地方（包括釋義文字）都是先**收起它上面的子彈窗**、回到這一層；收起之後再點父彈窗裡的詞，才會查新詞。這樣不會因為手滑在下面一層點了一下就丟掉正在看的那一層。
- MDX 詞典釋義裡自帶的交叉引用連結（「→ 參見某詞」那種）點了也是在彈窗裡重新查那個詞，不會把彈窗導航到別的頁面。
- 在首頁查詞頁、剪貼簿查詞這類獨立查詞介面裡，彈窗頂欄還有「後退」「前進」按鈕，可以在查過的詞之間來回翻。
- 電腦上的全域性查詞（應用外查詞卡片）同樣支援巢狀，見[能不能在任何軟體裡查詞](/faq/global-lookup.zh-HK)。

唯一的例外是「懸停即查詞」：懸停最多隻觸發一層彈窗，否則滑鼠在釋義上劃過就會連環彈出一串。要在彈窗裡繼續查，用點選。

## 加號制卡：一點就是一張 Anki 卡

連好 Anki 之後（見[怎麼連線 Anki](/faq/anki.zh-HK)），詞條旁的**加號**就是制卡按鈕。一張卡會自動帶上：詞頭、讀音、釋義、單詞發音、音調、詞頻，以及你查詞時所在的**原句**、截圖或影片片段、原聲——具體哪些進哪個欄位，由 **設定 → 制卡 → 欄位對映** 決定，用 Fushi 一鍵建立的 Lapis 卡組不用自己配。

幾個容易忽略的細節：

- **想用某一本詞典的釋義當主釋義**：長按那本詞典的標題，標題會變成主題色加粗，表示選中。這時制卡，主釋義欄位用的就是它，而不是排第一的那本。
- **這個詞已經在 Anki 裡**：加號會變成 ✓。再點它會彈出選擇：覆寫哪一張已有的卡、在 Anki 中開啟、新增為重複卡，或者取消。
- **原句不對 / 想多帶一句**：彈窗裡的「調整上下文」會開啟「選擇句子上下文」：可以前加一句、後加一句、編輯句子，有音訊的還能試聽，確認後再製卡。也可以先把幾句「加入制卡句子」，攢好再做成一張卡。
- **Anki 沒開**：卡不會丟，會進待發送佇列，下次連上自動送過去。

第一次做卡的完整流程見[第一張卡怎麼做](/faq/first-card.zh-HK)；Anki 那邊的設定建議見[連上 Anki 之後該怎麼設定](/faq/anki-basics.zh-HK)。

## 鍵盤、滑鼠、手柄怎麼操作彈窗

- **滑鼠滾輪**滾動彈窗；**Alt + 滾輪**跳到上一個 / 下一個詞條。滾動速度在 設定 → 查詞 → 詞條內容 的「彈窗滾輪速度」裡調。
- 「查詞彈窗」這組快捷鍵（滑鼠位於查詞彈窗上時生效）裡有「播放單詞發音」「制卡（加號）」「上一個詞條」「下一個詞條」，都可以在 **設定 → 快捷鍵設定** 裡改鍵。
- 手柄預設用方向鍵上下切換詞條。
- 手機上可以在彈窗上滑動關閉；能不能滑動關閉、滑動靈敏度和「彈窗關閉動畫」都在 設定 → 查詞 → 彈窗視窗 裡。

## 彈窗太大、太小、擋字怎麼辦

**設定 → 查詞 → 彈窗視窗**：

- **查詞視窗最大寬度 / 最大高度**：調彈窗尺寸；桌面端直接拖彈窗右下角也會改這兩個值。小說、漫畫、影片共用這一組。
- **底部停靠查詞彈窗**：不跟著被查的字走，固定成螢幕底部一條整寬麵板。可以按場景分開開（小說中 / 漫畫中 / 影片中 / 遊戲中底部停靠）。手機豎屏讀小說時很好用。
- **查詞彈窗瞬時滾動**：給墨水屏用，彈窗按固定距離跳動、不放滾動動畫。
- 豎排小說裡，彈窗會放在當前這一列的左邊或右邊，儘量不壓住正在讀的那一列。

## 常見狀況

- **點了沒反應 / 彈窗是空的**：先確認詞典已匯入且沒被隱藏；在首頁查詞頁輸入一個常見詞試試，查不到就是詞典問題。
- **結果總是一個字**：多半點在了詞的中間或詞尾，點詞頭的第一個字；也可能是缺少這類詞的詞典。
- **彈窗裡的字太小**：彈窗頂欄有放大 / 縮小查詞字號的按鈕，設定裡也有「詞典字號」。
- **同一個詞好幾本詞典內容重複**：把不常看的詞典往後排並摺疊，見[怎麼匯入詞典](/faq/dictionaries.zh-HK)。
