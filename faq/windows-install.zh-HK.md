Windows 版只有一種推薦裝法：到[下載頁](/zh-hk/download)點 Windows 那一行的「下載」，拿到 `fushi-<版本>-windows-setup.exe`，雙擊安裝。下載頁對這一行的說明是「含 Galgame 語音挖掘、桌面劃詞」——Galgame 文本 / 語音捕獲只在 Windows 上有，其他平臺沒有。

## 安裝包和免安裝 zip 選哪個？

**現在只發安裝包。** 下載頁以前有過一行「Windows（免安裝）」，對應解壓即用的 `-windows-x64.zip`（不建快捷方式、不註冊檔案關聯、也不會自動更新），後來已經下掉，GitHub Releases 裡現在的版本也只有 `-windows-setup.exe`。所以不用糾結，裝安裝包就行。

安裝包本身已經很「輕」，多數人擔心的幾件事它都不做：

- **不需要管理員許可權**。安裝器按當前使用者安裝（不彈 UAC），程式預設裝到 `%LOCALAPPDATA%\Fushi`，登錄檔只寫當前使用者這一側。
- **不搶預設播放器**。「檔案關聯」那一步只是把 Fushi 加進 mkv / mp4 等影片的右鍵「開啟方式」，安裝器原話是「這些選項不會更改你的預設播放器」。
- **桌面快捷方式可以不要**。「建立桌面快捷方式」預設勾選，取消即可；之後的自動更新不會把它重新建回來，也不會挪動你已經擺好的圖示位置。

如果你是從改名前的 Hibiki 升級上來的，直接裝新的安裝包即可，會原地升級，資料會自動遷移過來。

## 安裝步驟

1. 在[下載頁](/zh-hk/download)選「正式版」（日常推薦）或「除錯版」（最新功能先到這裡，區別見[正式版和除錯版有什麼區別？](/faq/channels.zh-HK)），點 Windows 行的「下載」。下載頁會在瀏覽器裡從多個來源分段併發拉取，拼好後做 SHA-256 校驗，顯示「SHA-256 校驗通過」才說明檔案完整；下載慢或失敗見[下載很慢或者打不開怎麼辦？](/faq/download.zh-HK)。
2. 雙擊 `setup.exe`。安裝嚮導是簡體中文介面，依次是：選安裝位置 →（僅全新安裝）選**資料儲存位置** → 選快捷方式和檔案關聯 → 開始安裝。
3. 勾上最後一頁的「啟動 Fushi」，第一次開啟會自動進入新手引導，按引導選功能、裝推薦包、連 Anki 就能用了，詳見[新手引導中途關掉了，怎麼重新開啟？](/faq/onboarding.zh-HK)。

## 程式裝在哪，資料又存在哪？

這是兩件事，安裝器也是分開問的：

- **安裝位置**放的是程式本身，體積不大。
- **資料儲存位置**放的是書、漫畫、封面、字幕、詞典和資料庫——安裝器提示「這些資料可能遠大於程式本身，建議選一個空間充足的位置」。預設是「文件」下的 `Fushi` 資料夾。推薦包（日語詞典 + 發音音訊庫）就有約 9.5 GB，C 盤緊張的話這一步直接選到別的盤。

這一頁**只在全新安裝時出現**；升級、重灌或應用內自動更新都不會再問，也不會動你已有的書庫。裝好之後想搬家，去 **設定 → 儲存 → 資料儲存位置** 裡遷移，Fushi 會連同資料庫裡記錄的路徑一起改好，不要自己手動剪下資料夾。資料是不是隻存在本機、會不會上傳，見[我的資料存在哪裡？會上傳嗎？](/faq/data.zh-HK)。

解除安裝時（Windows「設定 → 應用」裡解除安裝 Fushi）刪的是程式目錄，你的資料儲存位置不在程式目錄裡，想徹底清掉要自己去刪那個資料夾——刪之前確認有沒有需要的備份。

## 彈出「Windows 已保護你的電腦」（SmartScreen）怎麼辦？

Fushi 的 Windows 安裝包和程式檔案在釋出流程裡會做程式碼簽名。SmartScreen 除了看簽名，還會看這個檔案被多少人下載過；每個新版本剛發出來時下載量為零，偶爾仍可能彈出藍色的「Windows 已保護你的電腦」。這不代表檔案有問題：

1. 先確認檔案是從 fushi.moe 下載頁或 [GitHub Releases](https://github.com/hajisensai/Fushi/releases) 拿的，下載頁顯示過「SHA-256 校驗通過」。
2. 點提示裡的「更多資訊」，再點「仍要執行」。

防毒軟體誤報也是同理：Galgame 捕獲元件（隨安裝包一起裝在程式目錄的 `voice_hook` 下）需要往遊戲程序裡注入 DLL，這類行為偶爾會被安全軟體盯上。只有在你要用 Galgame 捕獲時它才會執行，被攔了可以把 Fushi 的安裝目錄加進殺軟白名單。

## 系統要求和常見坑

- **64 位 Windows**：安裝包是 x64 版，建議 Windows 10 / 11。閱讀器、查詞彈窗等介面用的是系統的 Edge WebView2 元件，Windows 10 / 11 一般已經自帶。
- **自動更新**：Fushi 會自己檢查更新，**設定 → 系統與關於** 的「更新設定」裡可以切「更新通道」、選「首選下載源」、手動「檢查更新」，開啟「自動安裝更新」後發現新版會自動下載、靜默安裝，再重新開啟 Fushi（不會重啟電腦）。通道怎麼選見[正式版和除錯版有什麼區別？](/faq/channels.zh-HK)。
- **更新時提示元件被佔用**：如果你正開著遊戲並用著 Galgame 捕獲，更新會提示「Galgame 捕獲元件被佔用」，先關掉遊戲再更新。播放器元件 `libmpv-2.dll` 被佔用時，按提示關掉殘留的 Fushi 程序，實在不行重啟一次 Windows 再裝。
- **裝到網路盤或行動硬碟**：資料儲存位置可以選外接盤，但啟動時那塊盤沒接上，Fushi 會卡在載入介面並提示你；點「重試」會用預設位置啟動這一次，原位置的資料不會被動。常年插著的盤才適合這樣用。
- **換電腦**：在舊電腦 **設定 → 同步與備份** 裡匯出一份備份，新電腦裝好 Fushi 後匯入；也可以開雲備份或[互聯備份](/faq/interconnect.zh-HK)，省得每次手動拷檔案。
- **手機和平板**：同一份書庫想在手機上看，用 [Fushi 互聯](/faq/interconnect.zh-HK)讓 Windows 電腦當主機，不用在每臺裝置上重複匯入。

其他平臺的裝法見 [Android 怎麼安裝 Fushi？](/faq/android-install.zh-HK)、[macOS 怎麼安裝 Fushi？](/faq/macos-install.zh-HK)，各平臺差異總覽見[支援哪些平臺？](/faq/platforms.zh-HK)。
