Fushi 的小說閱讀器有三種呈現方式：**翻頁**、**滾動**、**視覺小說**。它們讀的是同一本 EPUB、同一份進度，查詞和制卡的用法也完全一樣，差別只在「正文怎麼擺在螢幕上、怎麼往前走」。這篇講清楚每種模式的樣子、專屬設定和適合的場景。

## 在哪裡切換

兩個入口改的是同一個設定：

- 讀書時開啟 **閱讀設定 → 排版 → 常用 → 翻頁 / 滾動**，三個選項是「翻頁」「滾動」「視覺小說」；
- 不在書裡時，**設定 → 閱讀 → 模式與排版方向 → 翻頁 / 滾動**。

這是閱讀器的全域性設定，所有書共用。切換後當前章節會按新模式重新排版，閱讀位置保留在同一個字上，不會跳回章首。排版方向（豎排 / 橫排）是另一個獨立選項，三種模式都能和豎排、橫排任意組合。

## 翻頁模式：像紙書一樣一頁一頁翻

預設就是翻頁模式。正文按螢幕大小切成一頁一頁，翻一下換一整屏，頁面邊界固定，讀完一頁心裡有數。

- **怎麼翻**：左右滑動（桌面上滑鼠橫向拖動也行）、滑鼠滾輪、鍵盤方向鍵或 PageUp / PageDown；Android 可以開「音量鍵翻頁」。方向不順手，在 **閱讀設定 → 翻頁與手勢 → 翻頁方向** 裡有「反轉滑動翻頁方向」和「反轉鍵盤左右鍵翻頁方向」。滾輪翻得太快就調大「滾輪翻頁間隔」，手機上誤觸翻頁就調「滑動翻頁靈敏度」。
- **每頁列數**：只有翻頁模式有。預設「自動」，寬屏（平板橫放、電腦全屏）上可以手動設成 2 列甚至更多，像開啟的書一樣左右兩欄同時顯示；切到滾動或視覺小說時這一項會自動隱藏，因為那兩種模式根本不分欄。
- **跨頁模式**：針對插圖頁。開啟（或設為「自動」）後，相鄰兩張整頁插圖如果能拼起來，就並排成一張跨頁大圖顯示，「跨頁方向」可選從右到左（日文書）或從左到右。

適合：豎排日文輕小說、文庫本。翻頁模式最接近實體書的閱讀節奏，也最容易記住「讀到第幾頁」的位置感。

## 滾動模式：一整條長卷連續讀

滾動模式把一章排成一條連續的長卷，不分頁，手指一推就流過去。

- **橫排時上下滾，豎排時左右滾**——豎排滾動是橫向的長卷，從右往左推。
- 章節末尾留了一段空白，最後幾行能滾到螢幕舒服的位置再讀，不會貼著螢幕邊緣；繼續往前滾就進入下一章。
- 查完詞繼續滾動正文時，彈窗會自動關掉（**閱讀設定 → 查詞 → 關閉彈窗** 裡的「滾動時關閉查詞彈窗」，橫排豎排都生效），不用每次手動點掉。

適合：橫排的網路小說（尤其是從 [LNReader 外掛](/faq/novel-online.zh-HK)下載的那類章節很長、沒有排版講究的書）、手機單手讀、用觸控板或滑鼠滾輪慢慢推著讀的人。

## 視覺小說模式：一屏一段，逐字漸顯

視覺小說（VN）模式模仿 galgame 的文本框：螢幕上一次只出現一小段文字，讀完推進到下一屏。注意力被壓在眼前這幾句上，很適合精讀、跟讀，或者邊聽有聲書邊看。

它有一組只在這個模式下出現的設定，在 **閱讀設定 → 排版 → 視覺小說設定**：

- **每屏內容**：「一個段落」（預設，一屏放一段）或「按句子」。
- **每屏句數**：選「按句子」後出現，1–12 句，預設 1 句一屏。
- **保持對話完整**：按句子分屏時，把「」或『』括起來的一整段對白當成一句——哪怕裡面有好幾個句號，也不在中間切開。
- **文字漸顯速度**：新的一屏文字像遊戲裡一樣逐字出現，預設每秒 45 字，拉到 0 就是「立即顯示」。
- **點選空白處推進**：預設關。開啟後點正文空白處就推進到下一屏；如果此刻控制欄是收起的，第一下會先把控制欄叫出來，控制欄顯示著時再點才推進，所以不會出現「選單再也叫不出來」的情況。不開這一項時，用滑動、鍵盤或手柄推進。
- **有聲句保持在同一屏**（在「有聲書」頁裡）：配了有聲書時，避免一句朗讀被切到兩屏，聽到哪句就看到整句。

點詞查詞、點加號制卡在 VN 模式下和其他模式一樣；書裡的振假名也照常顯示。

適合：想一句一句啃的精讀、配有聲書的跟讀練習、習慣了 galgame 節奏的玩家。不適合需要快速掃讀、來回翻找前文的場景——想回看前文時用 **導航 → 目錄 / 搜尋** 跳過去更快。

## 到底選哪個？

| 你的情況 | 推薦 |
|---|---|
| 豎排日文輕小說，想要紙書的感覺 | 翻頁 |
| 平板橫屏、電腦全屏，螢幕很寬 | 翻頁 + 每頁 2 列 |
| 橫排網路小說，章節很長 | 滾動 |
| 手機單手、碎片時間讀 | 滾動 |
| 精讀、逐句查詞、句子挖掘 | 視覺小說（按句子，1–2 句一屏） |
| 邊聽有聲書邊看 | 視覺小說（開啟「有聲句保持在同一屏」）或翻頁 |

剛開始讀日語原版時，很多人發現視覺小說模式最不容易被滿屏的漢字嚇退：一屏只有一兩句，查完這幾個詞就能往下走，成就感來得快。讀順了以後再換回翻頁或滾動提速。三種模式之間來回切不丟任何東西，按當天的狀態選就行。
