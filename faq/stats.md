沉浸学习最容易让人放弃的地方，是感觉不到进步。Fushi 会在后台替你记账：看了多少分钟番、读了多少字轻小说、查了多少个词、做了多少张卡。这些数字不是用来攀比的，而是让你看见「这周比上周多读了两万字」「阅读速度从每小时三千字涨到了四千」——这种进步靠感觉是察觉不到的。

所有统计都只存在你自己的设备上，不注册、不上传（见[我的数据存在哪里](/faq/data)）。

## 统计在哪里看

- **首页顶部工具栏 → 统计中心**（柱状图图标），这是主入口。
- **阅读器里**：按 `I` 或从菜单打开「书内统计」，能看到本次阅读、本章 / 全书还需多久读完、本书累计的时长、字数、查词和制卡数；点「打开完整记录」直接跳到统计中心的阅读页签。
- 如果你在模块设置里关掉了首页：**设置 → 系统与关于 → 首页入口 → 统计中心**。

统计中心顶部有四个页签：**总览**、**阅读**、**观看**、**游戏**。总览把三个域加在一起，其余三个各管一类媒体。

## 统计中心里有什么

四个页签用的是同一套布局，从上往下：

1. **学习日历**：按天上色的日历，颜色越深学得越多；点某一天就切到那一天的数据。上面一行「过去一周」用火苗显示近 7 天里哪几天有学习。
2. **范围条**：选 **日 / 周 / 月 / 年 / 全部 / 自定义**，用「上一段 / 下一段」前后翻；翻到过去时会出现「今日 / 本周 / 本月 / 本年」一键回到当前。周按周一开始算；「自定义」可以任选起止日期。
3. **范围时长图**：所选范围内每天（范围很长时按周或按月）的学习时长柱状图。
4. **所选范围**卡片：这段时间的 **字数**、**时长**、**活跃天数**、**查词**、**制卡**、**收藏**（收藏的词）、**收藏语句**；观看页另有「看完」的集数，游戏页另有游玩「会话」数。阅读相关的地方会显示 **阅读速度**（多少「字/时」）。
5. **分析**（阅读、观看页的折叠区）：阅读页有趋势、速度摘要（加权均速、最快日 / 最慢日、典型日）、各来源（小说 / 漫画 / PDF 各占多少）；观看页有按小时的分布。
6. **最近沉浸**：最近的学习会话列表，「全部会话」看完整历史。
7. **按作品明细**：每本书、每部番、每个游戏各学了多久、多少字，可以按时长、字数或速度排序；点一行进入这部作品自己的会话列表。

首页的 **每日目标** 卡片可以「设定目标」（每日 / 每周字数，带快捷预设和「近 7 日日均」参考），这个目标统计的是阅读、视频字幕、游戏台词三类加起来的字数。

## 各个数字是怎么算的

知道口径，才能正确解读数字。

**阅读时长（小说 / PDF / 漫画）**

- 只有你真的在读的时候才计时。长时间没有翻页、滚动等操作，就停止计入——这个时长在 **设置 → 阅读 → 阅读统计 → 空闲判定时长** 里调，默认 10 分钟。
- 切到别的应用、打开菜单或全屏面板时停表；查词弹窗和制卡对话框不停表，它们本来就是阅读的一部分。
- **阅读计时开始方式**（同一分组）：**打开即开始**（默认）、**翻页后开始**（打开书先不计，翻过第一页或有声书开始出声才计）、**手动**。随时可以用阅读器里的计时按钮或 `P` 键暂停 / 继续。

**阅读字数 / 页数**

- 一页在你**翻走**的那一刻才计入「读过」。打开书扫一眼就关掉，不会算字数。
- 往回翻会撤回，再往前翻按并集恢复——同一页来回看只算一次，跳过没读的部分不算。
- 所以「阅读速度（字/时）」反映的是真实阅读量。速度至少要攒够 1 分钟样本才显示。

**观看时长（视频 / 番剧）**

- 按播放状态计时：在播就算，暂停不算；切到别的窗口但视频还在播，照常计。
- **只计第一次看到的部分**：回放上一句、拖回去重看、第二天重看同一集，都不再计时；快进跳过的部分也不算。所以一集 24 分钟的番，无论反复听几遍，观看时长最多就是 24 分钟。精听反复回放是好习惯，但统计里它不会被重复算。
- Jellyfin / Emby 等媒体服务器和互联远端的视频也照样统计。

**游戏**

- Windows 上用文本 Hook 抓到的 Galgame 台词计入字数；游玩时长按游戏会话记录，不满 60 秒的不入库。

**查词数、制卡数、收藏**

- 在阅读器、视频、游戏里查一次词、做一张卡、收藏一个词或一句话，都记到对应的媒体和日期上。

## 「今日」从几点开始

熬夜到凌晨两点看番，算今天还是昨天？在任意统计页范围条右侧点 **统计设置**，设 **「今日」从几点开始**（0–23 点整点，默认 0 点）。设成 4 点的话，凌晨 2 点的学习记到前一天。

注意：只有改设置之后写入的记录按新边界归日，已有的历史不会重新分桶。

同一个弹窗里还有 **清空统计**：清空当前页签那一类（在总览里则三类一起清）。清空统计不影响你收藏的词、句子、做好的 Anki 卡和游戏库，但不可撤销。

## 记错了怎么办

- **删掉一次误计的会话**：在「最近沉浸」或作品的会话列表里找到它，**删除会话**——比如开着书去吃饭忘了关、又把空闲判定调得很长。
- **编辑会话**：可以改一次会话的日期（整次会话挪过去，时刻不变）和字数。
- **删一部作品的统计**：「删除统计数据」会删掉该项的时长、字数与查词 / 制卡统计，收藏的单词和句子不受影响。
- 「清除全部会话」会清掉所有会话记录，需要二次确认。

## 多设备、多配置方案

- **配置方案（Profile）之间是隔离的**：切换到另一个 Profile，统计中心只显示这个 Profile 的数字（统计设置里会写明「仅显示配置 xxx 的统计」）。适合一台设备上学两门语言、或家人共用。
- **用 Fushi 互联**：「与已配对设备共享」里的 **共享统计**（阅读与观看时长、字数、查词与制卡计数）默认开启，手机和电脑的统计双向合并（见[互联教程](/faq/interconnect)）。
- **用云同步**：**设置 → 同步与备份 → 同步内容 → 同步统计**。两端要用同名的 Profile，统计才能对上。
- 游戏的统计不出本机。
- 备份文件里也可以带上统计数据，见[怎么备份和迁移数据](/faq/backup)。
- 从 **Hoshi Reader** 迁移过来的话，「第三方导入」可以把它的阅读统计一起导入。

## 怎么用这些数字

几个实用建议：

- **看趋势，不看单日**：某天只看了 10 分钟没关系，看月视图的柱状图是不是整体往上走。
- **阅读速度是最好的进步指标**：同类难度的轻小说，字/时持续上涨，说明你的阅读在变得自动化。
- **查词数 ÷ 字数**大致反映内容对你的难度：同一部作品读到后面查词变少，是正常的进步；如果一直很高，可以考虑换更简单的内容，见[可理解输入](/faq/comprehensible-input)。
- **制卡数别贪多**：每天做多少卡合适，见[每天做多少张卡合适](/faq/cards-per-day)。
- 想和别人比一比，可以试试实验性的排行榜（首页工具栏的「排行榜」），注册前不会上传任何数据。
