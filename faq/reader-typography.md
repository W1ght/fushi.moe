同一本 EPUB，换个字体、调大一点行距，读起来的累不累差别很大。Fushi 阅读器的排版选项都能在读书时当场调，改完正文立刻按新样式重排，不用退出书。这篇按「方向 → 字体 → 间距 → 振假名 → 主题和书籍样式」逐项说明，设置名都和 app 里一致。

## 在哪里调

- **读书时**：点正文空白处唤出控制栏，点 **阅读设置**。面板分几页：**主题与字体**（主题、正文字体、字体大小、字体粗细、振假名）、**排版**（模式、方向、行高、边距、高级选项）、**翻页与手势**、**有声书**、**查词**。面板里有一段日文示例文字做预览，调的时候能直接看到效果。
- **不在书里时**：**设置 → 阅读**，「模式与排版方向」和「排版」两组是同一批设置。

这些都是阅读器的全局设置，所有书共用一套。

## 竖排还是横排

**阅读设置 → 排版 → 常用 → 排版方向**：「竖排」或「横排」。默认是竖排，从右往左读，和日本文库本一致；读横排的网络小说、英文书或者不习惯竖排时切成横排。切换时阅读位置不会丢。

竖排有几项专属的细节调整，在 **排版 → 高级选项** 里（切到横排时自动隐藏）：

- **文字方向**：竖排里夹着的英文字母和数字怎么摆。「混合」（默认）让半角字母横躺着顺着行走，「竖直」让每个字母都立起来，和汉字一样一个个往下排。
- **字偶间距（纵排）**：启用字体自带的竖排字距调整，标点和小假名挤得更紧凑。
- **VPAL 纵排替代**：启用字体的竖排比例宽度字形，假名疏密更自然。只有字体本身带这些 OpenType 功能时才看得出差别。

翻页、滚动、视觉小说三种模式都能和竖排、横排任意组合，见[三种阅读模式怎么选？](/faq/reader-modes)。

## 字体、字号和粗细

**正文字体**：点进去是全 app 共用的**字体库**，可以：

- **导入字体文件**：选本机的 TTF / OTF 等字体文件；
- **从 URL 导入**：粘贴字体文件的下载地址；
- **添加系统字体**：直接用电脑上已经装好的字体；
- **推荐字体**：几款常用的中日文字体，点一下下载。

每一款字体可以勾选「字体用途」——「小说正文字体」「词典字体」「视频字幕字体」等互不干扰；多款字体拖拽排列优先级，排前面的优先用，缺字时才往后找。默认是「默认（书籍自带 / 系统字体）」，也就是不强行指定，用 EPUB 自己声明的字体，没有就用系统字体。

字体链还跟**内容语言**有关：同一个汉字，日文、简体中文、繁体中文的标准字形不一样，Fushi 按书的语言挑字体。EPUB 里声明了语言就自动用它；声明错了或者没声明，在书架上长按这本书，选「内容语言」手动指定。全局的默认值在 **设置 → 外观与交互 → 排版 → 默认内容语言**。

**字体大小**：8–128，默认 22。手机上一般 18–24 比较舒服，平板和电脑可以更大。**字体粗细**：100–900，默认 400（正常），屏幕偏淡或者字体太细时调到 500–600。

## 行高、段落和边距

- **行高**：1–3 倍，默认 1.65。竖排时就是列与列之间的距离；书带振假名时行高太小注音会挤，建议不低于 1.6。
- **段落间距**：段与段之间额外空出的距离，0–3em，默认 0。
- **段落缩进**：段首缩进几个字，默认 0（用书自带的缩进）。
- **两端对齐**：让每一行左右（竖排时上下）都对齐到边缘。
- **上 / 下 / 左 / 右边距**：按屏幕百分比算，默认左右各 2%、上下 0。手机上想多放字就调小，平板想留白就调大。
- **每页列数**：只在翻页模式下出现，默认「自动」，宽屏上可设成 2 列。

## 振假名（注音）

日文书里汉字上方的小字读音（ruby）怎么显示，在 **阅读设置 → 主题与字体 → 隐藏振假名**，四个选项：

- **关闭**（默认）：不隐藏，振假名原样显示；
- **点击显示**：振假名默认藏起来但位置保留（行距不跳），点一个词只揭开这个词的读音，这一下不触发查词——适合先自己猜读音、再核对；
- **隐藏**：完全不显示振假名；
- **淡显**：照常显示，但颜色变淡，不抢正文的视线，深浅主题下都有效。

还有一个快捷键「切换振假名」（默认绑在手柄右摇杆按下 R3，键盘没有默认键，可以自己绑，见[快捷键与手柄](/faq/shortcuts-gamepad)）：「点击显示」时一次揭开 / 收回整页注音，「淡显」时临时恢复全亮；「关闭」和「隐藏」时按了没有效果。查词本身不依赖振假名——即使隐藏了注音，点词照样能查到读音。

## 主题、书籍样式和插图

- **主题**：白色、米黄、护眼、水蓝、灰暗、深暗、纯黑，晚上读用深暗或纯黑（OLED 屏更省电）。
- **优先书籍样式**：默认开，尊重 EPUB 自带的 CSS（标题样式、特殊排版）。书的样式和你的设置打架时（比如书里写死了字号）关掉它，以你的设置为准。还不满意的话，在书架长按这本书选「编辑书籍 CSS」直接改这本书的样式表，改坏了可以「全部重置」。
- **图片模糊（防剧透）**：插图先模糊显示，点一下才揭开，避免翻页时被彩插剧透。
- **将插图页并入正文**：默认开，把只有一张图的单独章节并到相邻的正文里连续显示，不再单独占一页。

## 常见状况

- **改了字体没变化**：先看「优先书籍样式」是否开着、书的 CSS 是否写死了字体；再看字体库里这款字体有没有勾「小说正文字体」、排序是不是在前面。
- **竖排里的数字横躺着不好看**：把「文字方向」改成「竖直」。
- **振假名和上一行重叠**：调大行高。
- **中日文混排的字形看着像简体中文**：书的内容语言被识别错了，长按书选「内容语言」改成日语。
