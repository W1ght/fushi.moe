Fushi 的小说阅读器有三种呈现方式：**翻页**、**滚动**、**视觉小说**。它们读的是同一本 EPUB、同一份进度，查词和制卡的用法也完全一样，差别只在「正文怎么摆在屏幕上、怎么往前走」。这篇讲清楚每种模式的样子、专属设置和适合的场景。

## 在哪里切换

两个入口改的是同一个设置：

- 读书时打开 **阅读设置 → 排版 → 常用 → 翻页 / 滚动**，三个选项是「翻页」「滚动」「视觉小说」；
- 不在书里时，**设置 → 阅读 → 模式与排版方向 → 翻页 / 滚动**。

这是阅读器的全局设置，所有书共用。切换后当前章节会按新模式重新排版，阅读位置保留在同一个字上，不会跳回章首。排版方向（竖排 / 横排）是另一个独立选项，三种模式都能和竖排、横排任意组合。

## 翻页模式：像纸书一样一页一页翻

默认就是翻页模式。正文按屏幕大小切成一页一页，翻一下换一整屏，页面边界固定，读完一页心里有数。

- **怎么翻**：左右滑动（桌面上鼠标横向拖动也行）、鼠标滚轮、键盘方向键或 PageUp / PageDown；Android 可以开「音量键翻页」。方向不顺手，在 **阅读设置 → 翻页与手势 → 翻页方向** 里有「反转滑动翻页方向」和「反转键盘左右键翻页方向」。滚轮翻得太快就调大「滚轮翻页间隔」，手机上误触翻页就调「滑动翻页灵敏度」。
- **每页列数**：只有翻页模式有。默认「自动」，宽屏（平板横放、电脑全屏）上可以手动设成 2 列甚至更多，像打开的书一样左右两栏同时显示；切到滚动或视觉小说时这一项会自动隐藏，因为那两种模式根本不分栏。
- **跨页模式**：针对插图页。打开（或设为「自动」）后，相邻两张整页插图如果能拼起来，就并排成一张跨页大图显示，「跨页方向」可选从右到左（日文书）或从左到右。

适合：竖排日文轻小说、文库本。翻页模式最接近实体书的阅读节奏，也最容易记住「读到第几页」的位置感。

## 滚动模式：一整条长卷连续读

滚动模式把一章排成一条连续的长卷，不分页，手指一推就流过去。

- **横排时上下滚，竖排时左右滚**——竖排滚动是横向的长卷，从右往左推。
- 章节末尾留了一段空白，最后几行能滚到屏幕舒服的位置再读，不会贴着屏幕边缘；继续往前滚就进入下一章。
- 查完词继续滚动正文时，弹窗会自动关掉（**阅读设置 → 查词 → 关闭弹窗** 里的「滚动时关闭查词弹窗」，横排竖排都生效），不用每次手动点掉。

适合：横排的网络小说（尤其是从 [LNReader 插件](/faq/novel-online)下载的那类章节很长、没有排版讲究的书）、手机单手读、用触控板或鼠标滚轮慢慢推着读的人。

## 视觉小说模式：一屏一段，逐字渐显

视觉小说（VN）模式模仿 galgame 的文本框：屏幕上一次只出现一小段文字，读完推进到下一屏。注意力被压在眼前这几句上，很适合精读、跟读，或者边听有声书边看。

它有一组只在这个模式下出现的设置，在 **阅读设置 → 排版 → 视觉小说设置**：

- **每屏内容**：「一个段落」（默认，一屏放一段）或「按句子」。
- **每屏句数**：选「按句子」后出现，1–12 句，默认 1 句一屏。
- **保持对话完整**：按句子分屏时，把「」或『』括起来的一整段对白当成一句——哪怕里面有好几个句号，也不在中间切开。
- **文字渐显速度**：新的一屏文字像游戏里一样逐字出现，默认每秒 45 字，拉到 0 就是「立即显示」。
- **点击空白处推进**：默认关。打开后点正文空白处就推进到下一屏；如果此刻控制栏是收起的，第一下会先把控制栏叫出来，控制栏显示着时再点才推进，所以不会出现「菜单再也叫不出来」的情况。不开这一项时，用滑动、键盘或手柄推进。
- **有声句保持在同一屏**（在「有声书」页里）：配了有声书时，避免一句朗读被切到两屏，听到哪句就看到整句。

点词查词、点加号制卡在 VN 模式下和其他模式一样；书里的振假名也照常显示。

适合：想一句一句啃的精读、配有声书的跟读练习、习惯了 galgame 节奏的玩家。不适合需要快速扫读、来回翻找前文的场景——想回看前文时用 **导航 → 目录 / 搜索** 跳过去更快。

## 到底选哪个？

| 你的情况 | 推荐 |
|---|---|
| 竖排日文轻小说，想要纸书的感觉 | 翻页 |
| 平板横屏、电脑全屏，屏幕很宽 | 翻页 + 每页 2 列 |
| 横排网络小说，章节很长 | 滚动 |
| 手机单手、碎片时间读 | 滚动 |
| 精读、逐句查词、句子挖掘 | 视觉小说（按句子，1–2 句一屏） |
| 边听有声书边看 | 视觉小说（打开「有声句保持在同一屏」）或翻页 |

刚开始读日语原版时，很多人发现视觉小说模式最不容易被满屏的汉字吓退：一屏只有一两句，查完这几个词就能往下走，成就感来得快。读顺了以后再换回翻页或滚动提速。三种模式之间来回切不丢任何东西，按当天的状态选就行。
